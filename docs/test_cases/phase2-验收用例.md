## 关键技术难点与解决（详见 docs/pitfalls/）

- **必应对服务器 IP 连续查询限流**（第一个查询可靠、后续返回推荐流噪声）
  → 单综合查询 + 独立会话 + 查询间隔 + 双层过滤。见
  `docs/pitfalls/必应搜索对服务器IP连续查询限流.md`
- **urlparse 未导入致搜索解析静默失败** → 补导入
- **evaluate_script 返回双重编码 JSON** → 兼容解析

## 结论

Phase 2 **初步完整**：对话式自主攻略生成全链路跑通，需求解析→单查询搜索→
多来源抓取→过滤→综合生成图文攻略（带思考过程）→多轮修改→导出长图，
线上验证攻略质量高、来源干净、契合偏好、安全边界不变。
