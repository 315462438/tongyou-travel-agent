# Phase 81 · 目的地接力站与个人社交系统验收用例

日期：2026-08-10

## 自动化用例

### 后端

运行：

```bash
cd backend
.venv/bin/python -m pytest tests/test_social_api.py -q
```

覆盖：

1. 更新显示名、常驻城市、简介、旅行风格和头像，响应不包含密码或管理员字段；
2. 头像只能绑定当前账号上传的文件；
3. 好友申请、重复申请拦截、接收方接受、好友计数和删除完整；
4. 申请人不能处理自己发出的申请，不能添加自己；
5. 私密主页不出现在搜索中，陌生人无法打开，好友可以查看；
6. 私密作者的接力正文和阶段统计均不对陌生人可见；
7. 个人主页返回最近接力，但不返回私人会话、行程或记忆；
8. 现场情报生成 72 小时有效期；同一用户同一帖子只能保留一种反馈，再点取消；
9. 用户不能验证自己的接力，只有作者可以删除；
10. 未知阶段、内容类型和反馈类型被拒绝。

全量回归：

```bash
cd backend
.venv/bin/python -m pytest tests/ -q
```

结果：`781 passed`。

### 前端

运行：

```bash
cd frontend
npm test
npm run lint
npm run build
```

覆盖：首页入口替换、SocialHub 懒加载、接力/好友/主页三页、72 小时与隐私提示、头像类型、
公开开关、最近接力、公开主页加好友、移动底栏互斥和移动响应式规则。

结果：`58 passed`；lint 通过，存在 2 条与本功能无关的历史 Fast Refresh 警告；生产构建通过。

## 手工验收

1. 新账号登录后：首页只保留一个旅行输入入口，推荐区下方出现“真实旅行者接力”入口；
2. 打开同游圈：切换天堂寨/杭州等目的地和三个阶段，列表与数量同步；
3. 发布现场情报：页面显示有效截止时间；发布路线或问题时不显示 72 小时倒计时；
4. 第二账号验证内容：反馈单选、可切换、可取消；作者按钮禁用；
5. 好友页搜索第二账号：可申请，接收方可接受/忽略，双方好友数同步；
6. 将主页设为私密：陌生账号搜不到且打不开；已接受好友仍可打开；
7. 上传 PNG/JPEG/WebP 头像并保存：侧栏、主页和后续登录返回均同步；
8. 公开主页显示简介、旅行风格、接力/验证/好友统计和最近接力，不显示私人行程；
9. 删除好友不影响已经存在的协同行程；
10. 手机端四项底栏互斥，同游圈为全屏单列，关闭后回到原页面。
