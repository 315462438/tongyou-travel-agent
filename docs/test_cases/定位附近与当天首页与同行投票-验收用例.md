## 线上实测（2026-11-10，真实模型 + 高德）
- 合肥政务区坐标 + 「附近有什么洗浴中心」：查到 8 家并按距离排序（最近 712 米），回答按清单推荐，
  追问为「有马汤泉多少钱 / 能搓背的是哪家 / 哪家营业到很晚」，4 张地点卡。

## 手工验收
1. 手机上问「附近有什么好吃的」→ 首次弹定位授权 → 回答带距离，不反问在哪。拒绝授权 → 照常回答。
2. 给一个行程设出发日期为今天 → 首页顶部出现「今天 · 第 1 / N 天」卡，地点可导航；改成 3 天后 → 显示倒计时。
3. 行程里发起投票 → 另一成员收到通知、投票、改票 → 发起人结束投票。
