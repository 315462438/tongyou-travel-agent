# 直答配实景图 — 验收用例（2026-11-10）

自动化：`cd backend && .venv/bin/python -m pytest tests/test_direct_images.py -q`（17 passed）

| # | 场景 | 期望 | 用例 |
| --- | --- | --- | --- |
| 1 | 上一轮推荐了几家店，用户问「有没有图片」 | 回答里出现 `/travel/api/img` 图片，占位符不外露；每处最多 3 张、查询限定城市；prompt 明确禁止再说「纯文字助手」 | `test_asking_for_pictures_embeds_amap_photos` |
| 2 | 模型忘了写占位符 | 终稿在醒目提及处（标题/加粗）兜底插图 | `test_model_forgets_placeholder_still_gets_photo` |
| 3 | 普通直答（没要图、没联网） | 不调分类、不查高德，延迟不变 | `test_plain_question_does_not_look_up_images` |
| 4 | 要图但高德一张没有 | prompt 告知「没找到」，回答不出图也不谎称不能发图 | `test_no_photo_found_tells_model_to_say_so` |
| 5 | 高德查询抛异常 | 回答照常产出 | `test_lookup_failure_never_breaks_answer` |
| 6 | `direct_images_enabled=False` | 与改造前一致 | `test_disabled_flag_restores_old_behaviour` |
| 7 | 联网搜索轮 | 搜索结果进挑地点上下文；每处 1 张 | `test_web_search_turn_gets_one_photo_per_place` |
| 8 | 模型给的地点名带 Markdown 语法 | 清洗后才进查询与占位符 | `test_place_names_cannot_break_markdown` |
| 9 | POI 名称校验 | 只有品类词相同 / 只有头两个字相同的不算同一家（线上实测「天沐温泉」→「天沐养生SPA」） | `test_poi_name_must_match` |
| 10 | 首条 POI 名字不对或没图 | 向后取第一条名字对得上且有图的，图片去重 | `test_search_poi_photos_skips_mismatched_and_photoless` |
