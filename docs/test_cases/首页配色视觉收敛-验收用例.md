# 首页配色视觉收敛：验收用例

## 自动化测试

执行：

```bash
cd frontend
npm test
npm run lint
npm run build
```

| 用例 | 检查点 | 预期 |
| --- | --- | --- |
| 首页标题契约 | `.hero .hero-title` | 整句使用同一组深海军蓝到皇家蓝渐变，无白纹、描边、投影和动画 |
| 品牌短句可见 | `.hero-eyebrow` | 不得被 `color: transparent` 覆盖 |
| 输入区交互色 | `.inspiration-launchpad.simple` | 默认与 focus-within 均为皇家蓝/天空蓝色系 |
| 旧色防回归 | Phase 47 首页样式区 | 不包含旧蓝紫、松绿或青蓝焦点/描边的代表色值 |
| 接力横幅 | `.social-entry` | 深皇家蓝底，光晕不含旧松绿、青蓝或紫色 |
| 侧栏品牌字 | `.brand-name` | `17` 为皇家蓝、`同游` 为深皇家蓝，不再出现红黑分色 |
| 设计系统闸门 | 全局 CSS | 字号与硬编码颜色数量继续满足既有上限 |

## 人工视觉验收

桌面端打开新会话空状态，确认：

1. 侧栏为浅蓝灰，主区为冷白，能分层且不发黄；
2. 标题每个字使用一致的深海军蓝到皇家蓝纵向渐变，不按词分色且没有白色横纹；
3. 点击主输入框后只出现皇家蓝描边/光晕；
4. 接力站横幅为深皇家蓝，不再偏绿、偏青、偏褐或冒紫光；
5. 热门目的地卡片仍保持四列，无横向溢出；
6. 切换到移动版后，标题、输入区、接力横幅和卡片均无裁切。
