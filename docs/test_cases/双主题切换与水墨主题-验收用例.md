# 双主题切换与水墨主题：验收用例

## 自动化测试

执行：

```bash
cd frontend
npm test
npm run lint
npm run build
```

| 用例 | 预期 |
| --- | --- |
| 缺失主题存储 | 回退 `modern` |
| 存储值为 `ink` | 初始化为水墨主题 |
| 非法存储值 | 回退 `modern`，不注入未知 class |
| 顶栏主题按钮 | 有 `aria-pressed`、动作标签和水墨笔 SVG |
| 根节点主题 class | 输出 `theme-modern` 或 `theme-ink` |
| 水墨背景资源 | PNG 存在且构建产物包含该文件 |
| 水墨标题 | 使用楷体回退链与实心墨色 |
| 水墨主按钮 | 使用浓墨渐变和朱砂 focus |
| 移动端主题按钮 | 隐藏文字但保留按钮与可访问名称 |

## 人工视觉验收

1. 现代主题下页面与当前皇家蓝版本一致；
2. 点击“水墨主题”后，首屏出现低对比度山水背景，不遮挡标题和输入框；
3. 标题、侧栏、主按钮、接力横幅、热门卡片形成宣纸/墨/朱砂体系；
4. 热门图片被适度降饱和，但仍能辨认目的地；
5. 刷新页面后仍保持水墨主题；
6. 点击“现代主题”后彻底恢复皇家蓝主题；
7. 移动端按钮不挤压顶栏，水墨背景不产生横向滚动。
