## 用例列表

### 1. 打字机平滑纯函数（自动化 ✅）

| 用例 | 断言 |
| --- | --- |
| 无积压即完成 | `typewriterStep({shown:5}, 'abcde')` → `{shown:5, done:true}` |
| inactive 直接追平 | `typewriterStep({shown:2}, 'abcde', {inactive:true})` → `{shown:5, done:true}` |
| 速率自适应 | 积压 >400→6 字符/步；>200→4；>100→2；≤100→1 |
| 追平即 done | 最后一步恰好到达长度时 `done:true` |
| 不越界 | 目标意外变短时对齐到目标长度 |

### 2. 消息增量合并纯函数（自动化 ✅）

| 用例 | 断言 |
| --- | --- |
| 完全未变 | 返回原数组（引用相等），`React.memo` 可跳过重渲染 |
| 流式增长 | 只替换变化消息，其余保持原引用 |
| 新增消息 | 追加，旧消息引用不变 |
| 终稿/停止 | content 不变但 meta 去 streaming → 仍替换（`_ensure_stopped_message` 场景） |
| 空 prev | 直接返回 next |

### 3. 后端流式节拍配置（自动化 ✅）

| 用例 | 断言 |
| --- | --- |
| 默认值 | `streaming_flush_interval_s == 0.5` 且落在 0.1-2.0 合理区间 |
| env 覆盖 | `STREAMING_FLUSH_INTERVAL_S` 可覆盖（部署调参路径） |

### 4. 手工验收（线上/本地 dev 验证）

- [ ] 发一条攻略请求：正文以连续流动方式出现，不再有「停顿 ~2s → 跳出一大段」的观感；
- [ ] 生成中途点「停止」：已生成部分**瞬间**补全显示（打字机立即追平），无残留 cursor；
- [ ] 终稿落地瞬间：正文立即完整显示，不等待打字机播完；
- [ ] 切回一个正在流式生成的会话：已有内容直接显示（不重放动画），新内容继续平滑追加；
- [ ] 长会话（50+ 消息）轮询期间滚动无卡顿（未变化消息不重渲染）；
- [ ] 表格/图片占位符在流式中不闪残片（`_embed_images(streaming=True)` 行为不变）；
- [ ] 移动端与 `prefers-reduced-motion` 场景无异常（动画粒度小，未引入新动效依赖）。
