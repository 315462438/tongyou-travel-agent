## 自动化（后端 26 条）

| 组 | 用例要点 |
| --- | --- |
| 角色 | 升级 / 降级 / **不能改自己** / **不能降最后一个管理员** / 未知用户 404 |
| 邀请码 | 默认 5 人配额 / 排除易混字符 `0O1IL` / 用满失效 / 大小写不敏感 / 停用后保留行 / **并发不超卖** / 没配任何码时开放注册 |
| 公告 | 发布即所有人未读 / 标记已读 / 按用户隔离 / 重复标记幂等 / 撤下同时清已读行（否则未读会算成负数） |
| 上传 | 四种真图识别 / **拒绝伪装成图片的 php、zip、svg** / 落盘名不含用户文件名 / 超限 413 / **落盘路径与返回 id 一致** / 两次上传不覆盖 |

## 人工走查

| 用例 | 步骤 | 期望 |
| --- | --- | --- |
| M1 侧栏展开 | 桌面端点左上角折叠图标收起侧栏 | 左上角出现展开按钮，点击可展开（回归） |
| M2 升级管理员 | admin → 用户管理 → 某用户「设为管理员」 | 二次确认后成功，该用户刷新后能看到管理面板 |
| M3 防呆 | 对自己点「取消管理员」 | 报「不能修改自己的角色」 |
| M4 最后管理员 | 只剩一个管理员时降级 | 报「这是最后一个管理员」 |
| M5 邀请码 | 生成一个 5 人码 → 复制 → 注册 5 个账号 | 第 6 个提示「无效或已用完」 |
| M6 公告 | admin 发布公告 | 其他账号顶栏喇叭出现红点，点开可读，读后红点消失 |
| M7 撤下 | admin 撤下公告 | 所有账号列表里消失，未读数不为负 |
| M8 表情 | 客服/群聊点 😊，把光标放句中再选表情 | 表情插在**光标处**，不是追加到末尾 |
| M9 截图 | 截图后在输入框直接 Ctrl/⌘+V | 自动上传并作为一条图片消息发出 |
| M10 图片 | 点 🖼️ 选一张 >5MB 的图 | 提示超限，不产生半截文件 |
| M11 中文输入 | 输入拼音时按回车选词 | 只确认候选词，**不发送** |
| M12 群聊图片 | 行程群聊发图 | 同行者可见，点击可看大图 |

## 边界（明确不做）

- 图片取回**不鉴权**（`<img>` 不能带 header，与 `/api/img` 同一先例）：
  知道 uuid 的任意人可取图。不做「仅会话双方可读」——那要跨客服/行程两套成员模型。
- 表情用 Unicode emoji，不做自定义表情包。
- 公告无「定向推送/分组」，一次给全部账号。
