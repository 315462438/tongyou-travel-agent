# Phase 86：协同行程参考稿视觉重构验收用例

## 自动化测试

执行：

```bash
cd frontend
npm test
npm run lint
npm run build
```

对应自动化用例位于 `frontend/tests/visual-regressions.test.mjs`：

1. `collaborative trip follows the reference layout while inheriting platform colors`
   - 校验统一桌面导航存在并能切换助手标签、自动展开右栏。
   - 校验协同行程颜色继承平台 token，不包含参考稿的米色/棕橙主题色。
   - 校验地图取消旧的 680px 最大宽度，继续占据主工作区。
2. `collaborative trip keeps mobile pane navigation after the desktop restyle`
   - 校验窄屏和显式移动布局隐藏桌面导航。
   - 校验移动端继续展示地图与助手内部标签。
   - 校验地点操作按钮在手机端维持可点击触区。
3. `desktop trip board uses budget-days, event timeline, and map columns`
   - 校验桌面主体为 220–270px 预算/天数侧栏 + 弹性事件区 + 370–430px 地图区。
   - 校验预算、实际支出、使用进度、每天日期与事件数都存在。
   - 校验中间只渲染当前 Day 的事件，并使用纵向时间轴连接事件卡。
   - 校验功能标签只替换中间内容，左右两侧位置保持不变。

## 人工验收

### TC-86-01 桌面整体布局

- 前置：打开一份包含 5 天以上、多个地点的协同行程。
- 步骤：使用宽度 1440px 以上桌面窗口查看行程板。
- 预期：
  - 顶部为平台蓝紫体系下的双层导航，背景、边框和强调色与主站一致。
  - 左侧是预算和行程天数，中间是事件时间线，右侧是约 370–430px 地图。
  - 预算卡显示总预算、已花费和进度；Day 项显示日期与事件数量。
  - 三栏边界清楚，内容区无横向滚动。

### TC-86-02 统一胶囊导航

- 步骤：依次点击 Day 1、Day 2、住宿、费用、动态、助手。
- 预期：
  - 当前 Day 使用平台主色实底胶囊；地点计数可见，中间只显示该 Day 的事件。
  - 功能标签使用平台浅色底，当前功能有白底与主色文字。
  - 点击任一功能标签时，中间事件被对应功能内容替换，左侧预算/天数和右侧地图保持原位。

### TC-86-03 时间线卡片

- 步骤：展开某一天，悬停地点卡，查看时间、标签、备注和操作按钮；拖动地点调整顺序。
- 预期：
  - 白色卡片、平台灰蓝边框和小幅阴影符合参考稿层次。
  - 时间以平台浅蓝紫胶囊呈现，备注和标签不抢主标题。
  - 悬停只轻微上浮，不造成列表明显跳动；拖动、编辑、评论、删除均可用。
  - 时间标签显示“开始 – 结束”时间段；有停留时长时正确跨小时/跨午夜计算。
  - 无停留时长时使用下一事件开始时间；没有可用结束时间时显示“待定”，不伪造时长。

### TC-86-04 地图与层叠

- 步骤：切换日期、点击地点定位、打开行程操作菜单、群聊、编辑弹窗。
- 预期：
  - 地图随日期更新并占满中央卡片，不被限制为窄小正方形。
  - 行程操作菜单和板内弹窗始终位于地图上方。
  - 群聊抽屉正常打开，地图 marker 不覆盖抽屉。

### TC-86-05 功能视图返回行程

- 步骤：点击顶部“住宿”或“助手”，再点击左侧“返回 Day N 行程”。
- 预期：左侧恢复当前 Day 的事件列表，右侧地图全程不跳位。

### TC-86-06 移动端

- 前置：切换为应用内移动版，或将视口收窄至 720px。
- 步骤：分别进入“行程 / 地图 / 助手”，再在助手内切换住宿、费用和动态。
- 预期：
  - 一次只显示一个主面板，桌面统一导航不出现。
  - 地图与助手内部标签仍可操作，无功能入口丢失。
  - 页面无横向溢出；地点操作按钮触区清晰；安全区布局不退化。

### TC-86-07 减少动态

- 前置：系统开启“减少动态效果”。
- 步骤：悬停胶囊、地点卡与按钮。
- 预期：无位移型动画，内容与状态仍清晰可辨。
