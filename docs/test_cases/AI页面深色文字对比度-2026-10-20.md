# AI 页面深色文字对比度

自动化：`frontend/tests/ai-contrast-browser.mjs`；启动 Vite 4185 后在 frontend 执行 `npm run test:ai-contrast`，可设置 PLAYWRIGHT_MODULE / CHROME_PATH。

- 桌面 1559×900、手机 Web 390×844、Android 样式 390×844，逐个切换浅→深→浅（9 次检查）。
- 检查标题、上方引导、说明、输入标签、输入内容、placeholder、上传按钮与说明、规划开关、状态提示、快捷任务和顶栏按钮。正常文本前景/背景 alpha 合成对比度 ≥4.5，标题 ≥3；读取实际文字填充，防止透明渐变遗漏。
- 输入卡不得遗留浅色背景渐变；切换外观前后输入框几何尺寸及草稿相同。
- fixture 拦截业务接口，不操作生产用户数据。结果和截图默认 `/tmp/tongyou-ai-contrast`。
- 手工查看桌面浅/深与移动深色截图，确认玻璃卡片和文字配色匹配。自动对比度不是整页所有渐变像素的审计。
