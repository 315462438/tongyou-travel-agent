## 自动化

| 用例 | 断言 |
| --- | --- |
| A1 排除内部账号 | evalbot 刷 10 条成都也不得进热门榜（否则榜单被评估跑测污染） |
| A2 多城拆首城 | 「武汉,开封,洛阳,西安」→「武汉」，不出现念不出来的 chip |
| A3 包含去重 | 「平潭岛」与「福建平潭岛」合并，保留更短的 |
| A4 按热度排序 | 出现次数多的在前，且拆首城后去重 |
| A5 时间窗 | 超过 30 天的会话不进榜 |
| A6 无数据 | 返回空数组（前端回退静态示例，不白屏） |
| A7 常驻城市 | 从记忆 `常驻城市` 解析出「合肥」 |
| A8 无常驻城市 | 返回空串，**不凭空编出发地** |
| A9 has_history | 有无会话正确反映 |
| B1 热门 chip | 用真实目的地生成，有常驻城市时带出发地，无则不带 |
| B2 首屏只 3 张 | 不刷屏 |
| B3 三下起步 | 只点一项也能成句；「不确定」转成自然表达而非原样塞入 |
| B4 不再写死成都 | `Home.tsx` 不再直接渲染静态 CHIPS（含 composer「+」菜单） |
| B5 回退 | 拿不到 trending 时仍渲染静态示例 |

## 边界

- 不做定位/IP 归属地推断。
- 热门榜是**平台级**社会证明，不是个人推荐——新用户没有个人数据。
- 榜单受历史累计影响：老目的地（杭州/拉萨）票数高于昨天的新目的地（平潭岛/武功山）。
  数据量大起来后如仍偏旧，再考虑按时间加权。
