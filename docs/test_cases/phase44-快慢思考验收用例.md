# Phase 44 验收用例 — 快/慢思考语义重排

对应自动化测试：`backend/tests/test_deep_research.py`（路由测试组重写）。

## A. 自动化

| # | 用例 | 预期 |
| --- | --- | --- |
| A1 | decide_route 纯分类 | 不再做开关门控（research/direct 原样返回），失败/未知/空 → guide |
| A2 | 开关开（慢思考） | direct 类仍秒回；guide 类走攻略流水线；research 类走深研（未启用退 guide）；均无提示卡 |
| A3 | 开关关（快思考） | 一律 direct；guide/research 类挂提示卡；direct 被禁时退 guide 兜底 |

## B. 线上手工回归

1. **开关关** + 「帮我规划武汉至拉萨13天」→ 秒级快答（无「已深度思考」折叠、无来源、
   无配图）+ 提示卡「已用快速模式作答…打开深度推理重新提问」；
2. **开关开** + 同样问题 → guide 流水线：搜索/读页进度气泡、「已深度思考」折叠、
   配图、来源卡；
3. **开关开** + 「厦门 vs 青岛哪个适合亲子」→ 深度研究（多来源报告）；
4. **开关开** + 「谢谢」→ 仍秒回（不跑重流水线）；
5. 快答速度：首字应明显快于原 direct（换了快模型）。
