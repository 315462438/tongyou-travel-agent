## 可重复执行

```bash
xcrun devicectl device info details --device 4670F021-7FFB-5BEB-A805-01B9708727D4 --json-output /tmp/tongyou-ios-target-details-20261024-latest.json
xcodebuild -project ios/Tongyou.xcodeproj -scheme Tongyou -configuration Release -destination 'id=00008150-0004550E26E8C01C' -derivedDataPath /tmp/tongyou-ios-connected-20261024 -allowProvisioningUpdates -allowProvisioningDeviceRegistration clean build
codesign --verify --deep --strict /tmp/tongyou-ios-connected-20261024/Build/Products/Release-iphoneos/Tongyou.app
xcrun devicectl device info apps --device 4670F021-7FFB-5BEB-A805-01B9708727D4 --bundle-id com.yuchengjiang.tongyou --json-output /tmp/tongyou-ios-connected-after-20261024.json
xcrun devicectl device process launch --device 4670F021-7FFB-5BEB-A805-01B9708727D4 --json-output /tmp/tongyou-ios-connected-launch-20261024.json com.yuchengjiang.tongyou
```

安装及启动结果由 JSON 断言验证：install/launch 的 `info.outcome == success`，安装版本为 1.0.22、构建号 23，签名 profile 包含目标设备且未过期，processes 中包含 launch 返回的 PID。此次所有断言通过。
