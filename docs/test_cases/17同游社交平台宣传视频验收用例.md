# 17同游社交平台宣传视频验收用例

## 自动验收

运行：

```bash
bash marketing/promo-2026-08-24/verify_dynamic_video.sh
```

应满足：

- 文件存在且非空。
- 视频编码为 H.264。
- 分辨率为 1920×1080，帧率为 30 fps。
- 时长在 48–58 秒之间。
- 网页主体不做持续缩放；抽取同一静态场景的首尾帧，文字边线位置保持一致。
- 大章节至少出现 5 次横向卡片翻转转场。

## 视觉抽检

1. 0 秒：网页端首页和品牌完整可读。
2. 3–7 秒：需求文字连续补全，有输入过程。
3. 9–14 秒：思考进度从理解需求推进到检查优化。
4. 15–26 秒：攻略从流式首段到完整图文、预算表。
5. 27–34 秒：协同行程路线和地点编号清晰。
6. 35–38 秒：群聊气泡不贴边、不遮挡。
7. 24–28 秒：来源、图片和“查看原文”入口清晰。
8. 36–43 秒：住宿、费用、预约检查和海报导出完整。
9. 43–52 秒：同游圈和品牌 CTA 完整。


## 隐私与内容检查

- 不出现密码、令牌、手机号、邮箱或个人精确位置。
- 不出现无关或恶意历史会话标题。
- 演示不产生新的线上规划、聊天或行程变更。
