# 17同游社交平台宣传视频验收用例

## 自动验收

运行：

```bash
bash marketing/promo-2026-08-24/verify_video.sh
```

应满足：

- 文件存在且非空。
- 视频编码为 H.264。
- 分辨率为 1080×1920，帧率为 30 fps。
- 时长在 30–45 秒之间。

## 视觉抽检

1. 0 秒：品牌与痛点钩子完整可读。
2. 6 秒：需求输入与参数卡无裁切。
3. 12 秒：思考进度和五阶段工作台清晰。
4. 21 秒：协同行程路线和地点编号清晰。
5. 27 秒：群聊气泡不贴边、不遮挡。
6. 32 秒：同游圈现场情报卡清晰。
7. 35 秒：品牌收口和 CTA 完整。

## 隐私与内容检查

- 不出现密码、令牌、手机号、邮箱或个人精确位置。
- 不出现无关或恶意历史会话标题。
- 演示不产生新的线上规划、聊天或行程变更。
