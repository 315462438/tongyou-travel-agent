## A. 自动化

| # | 用例 | 预期 |
| --- | --- | --- |
| A1 | 分享全流程 | owner 开启（幂等）/editor 403；免登录预览只回 title/destination/inviter/人数；token 加入即 accepted 且幂等；重置后旧 token 预览与加入均 404；关闭后 404 |

## B. 线上手工回归（真实微信流程）

1. A 打开行程板 →「🔗 分享」→ 复制微信文案 → 发给 B；
2. B（**无账号**）微信里点链接 → 落到登录页（join token 已暂存）→ 注册 →
   **自动弹出该协同板**，头像出现在成员区；A 侧修改记录出现「通过分享链接加入」；
3. B（已有账号但未登录）点链接 → 登录 → 同样自动进板；
4. A「重置链接」后旧链接再点 → 加入失败（无提示崩溃即可）；「关闭分享」同理；
5. 微信内置浏览器打开 IP 链接会有「非官方网页」提示——**属预期**，等域名+备案+HTTPS
   上线后消失（备案通过后迁移时统一处理）。

## 边界

- 链接即凭证（拿到即可加入），owner 可随时重置/关闭；成员上限 20；
- 分享文案里的域名跟随当前访问地址（`location.origin`），迁移到 17tongyou.com 后自动变。
