# 图片降级必须告知模型 — 验收用例（Phase 112）

自动化：`backend/tests/test_image_prep.py`（19）、`backend/tests/test_vision.py`（27）、
`backend/tests/test_image_failure_visible.py`（5）。

## 一、规格化产物带降级说明（`test_image_prep.py`）

| # | 场景 | 期望 |
| --- | --- | --- |
| 1 | 规格内的图（800×600） | `notices == []`、`degraded is False`、字节原样返回 |
| 2 | 超宽图（2000×400，上限 500） | notices 含 `2000×400` 与 `500×100` **两个尺寸** |
| 3 | 需先缩宽再缩高（2000×40000，上限 500 / 2 片） | 缩放说明**只有一条**，且报的是原图与最终尺寸，不是逐次 resize 的流水账 |
| 4 | 切片（300×2000） | `tiled is True`，notices 说明「同一张长图」 |
| 5 | 解码失败 | 仍原样返回（退化方向不变）**且** `degraded is True` |
| 6 | 没装 Pillow | 同上——超大图必然读不出来，不能静默 |

**为什么第 1 条重要**：每张图都贴一句「一切正常」会让真正的降级淹没在噪声里，
也白占 prompt。「没事就别说话」是这套机制能用的前提。

## 二、读图结果分内容与说明两路（`test_vision.py`）

| # | 场景 | 期望 |
| --- | --- | --- |
| 7 | 3 张全部正常 | `note == ""`、`any_unread is False`、`ok == total` |
| 8 | 3 张读出 1 张 | `total=3 / ok=1`、`any_unread is True`、`bool(reading) is True`（产出仍可用）、note 含「共 3 张，成功读取 1 张」且**逐条**说明 2 张的原因 |
| 9 | 图被缩过 | note 含原始尺寸与「细小文字可能不准确」 |
| 10 | 渲染上限砍了列表 | note 含「共 N 条，此处只列前 M 条」 |
| 11 | 说明与内容分开 | `【读图说明】` 在 `.note` 里，**不在** `.text` 里 |
| 12 | 视觉关闭 | `.text == ""`（行为与改造前一致） |

**第 8 条是本次的核心**：改造前 `desc` 非空就判定「读到了」，部分失败完全不吭声，
而前面刚播过「正在看你发的 3 张图…」。

## 三、失败必须走到用户与模型面前（`test_image_failure_visible.py`，AST 护栏）

| # | 断言 | 防的是 |
| --- | --- | --- |
| 13 | 存在 `if <reading>.any_unread:` 分支且调 `_image_unreadable` | 判据回到「产出空不空」这个**形状**上（同 Phase 111「别靠文案认出自己发过的消息」） |
| 14 | 存在 `if <reading>.note:` 分支且赋值给 `user_text` | 说明只是个没人读的字段 |
| 15 | 该分支内**没有** `wrap_external` | 我们自己的话被混进外部内容标签，审计时分不清 |
| 16 | 视觉调用的 `except` 分支仍调 `_image_unreadable` | 400/超时静默 |
| 17 | `_image_unreadable` 发 progress 时带 `meta` | 被 `clear_plain_progress` 清掉，用户永远看不到 |

## 四、变异检验（必须能红）

- 删掉 `image_prep` 里的 notice 生成 → 用例 2/3/4/5/6 红。
- 把 `if reading.any_unread` 改回 `if reading.text` → 用例 13 红。
- 把 `reading.note` 包进 `wrap_external` → 用例 15 红。
- 把「共 N 条，此处只列前 M 条」改回只写 logger → 用例 10 红。

## 五、手工复验（线上）

1. 一次传 3 张图，其中 2 张故意用超大/损坏文件 → 进度出现「你发的 3 张图里，我只读出了 1 张」，
   反问走 `_BLIND_ASKS` 而不是「请问目的地是哪里」。
2. 传 Phase 111 那张 1800×25242 行程截图 → 说明里出现原始尺寸；助手不再把缩糊的价格当确定值。
