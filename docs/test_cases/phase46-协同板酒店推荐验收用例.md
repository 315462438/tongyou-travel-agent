## B. 线上手工回归

1. 打开行程板右栏「🏨 酒店推荐」→ 默认城市=目的地 → 点「查酒店」→ 秒级出高德酒店
   （名称/⭐评分/地址）；
2. 某家点「＋ 加入行程」→ 作为「🏨 住宿」条目落到当前选中天 → **自动上地图 marker**
   （带坐标，不重新地理编码，多城行程也定位准）；
3. 城市输入框改成 成都/康定 等 → 查该城酒店（适配多城行程分城订房）；
4. 点「💰 查携程实价（跳转对话，较慢）」→ 关板、新建对话、自动发「查XX的酒店，要携程
   实时价格…」并**已开深度推理** → 走 guide/携程流水线出真实酒店卡片+实价。

## 架构取舍

- 携程实价**不内联板中**（30-60s 浏览器抓取 + 登录墙会卡实时板），跳转对话是正确的
  「按需」——慢工作回到聊天流水线（用户预期等待的地方），复用全部携程机器零新增抓取代码；
- 高德酒店无实时价格，面板注明。
