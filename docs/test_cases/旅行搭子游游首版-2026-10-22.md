## 可运行用例

### 逻辑与构建

```bash
cd frontend
npm test
npm run build
npm run lint
```

```bash
cd backend
.venv/bin/python -m pytest tests/test_guide_quick_take.py tests/test_cancel.py tests/test_streaming_flush.py -q
```

在仓库根目录：

```bash
xcrun swiftc -module-cache-path /tmp/tongyou-pet-module-cache ios/Tongyou/Core/TravelPet.swift ios/tests/TravelPetTests.swift -o /tmp/tongyou-pet-tests
/tmp/tongyou-pet-tests
```

### 浏览器

在独立终端启动 `frontend` 的 Vite，4191 端口。浏览器脚本默认使用该地址；可用 `PET_QA_URL` 和 `JOURNEY_QA_URL` 改写。

```bash
PLAYWRIGHT_MODULE=/private/tmp/tongyou-qa/node_modules/playwright/index.mjs PET_QA_OUTPUT=/tmp/tongyou-pet-browser node frontend/tests/travel-pet-browser.mjs
PLAYWRIGHT_MODULE=/private/tmp/tongyou-qa/node_modules/playwright/index.mjs JOURNEY_QA_URL=http://127.0.0.1:4191/travel/ node frontend/tests/journey-browser.mjs
```

Playwright 可由本机模块路径提供，未设置时使用通常的 `playwright` 包。测试浏览器为独立 Chrome，不加载用户 profile。

每组检查：

- 初始不增加行程轮询；轻点仍直接问 AI，收起后草稿保留。
- 长按只打开旅行工具；拖动只换边，不触发对话；左右均不与导航重叠。
- 摸摸有回应；减少动态效果后动画为 none；隐藏保留 AI，刷新后设置仍在。
- 出发检查读取真实接口形状的日期、位置、时间与 issues；失败不显示成功，重试能恢复，空列表有明确空态。
- 真实 running → 完成与用户停止分开；部分正文在停止后也不能误显示完成。
- 打开地图工作台时角色收起；首次成员快照不欢迎，新增成员欢迎一次，普通 presence 更新不重播。
- 覆盖 320×780 Android、390×844 Android 深色、430×932 Web 手机、1280×900 桌面、844×390 横屏；检查水平溢出和浏览器错误。

纯逻辑另覆盖当前轮隔离、来源确认回复解除等待、初步回答不算终稿、错误标记、设置损坏、成员移除/换序/重复以及 no_location 地点。

### iOS UI

```bash
xcodebuild -project ios/Tongyou.xcodeproj -scheme Tongyou -configuration Debug -destination 'platform=iOS Simulator,id=3BAB7D45-20DC-48A1-8128-505780F78019' -derivedDataPath /tmp/tongyou-pet-ios -parallel-testing-enabled NO -only-testing:TongyouUITests/TravelPetUITests -only-testing:TongyouUITests/JourneyUITests CODE_SIGNING_ALLOWED=NO test
```

- 长按进入工具，触摸回应，准备清单读取日期和未定位地点；减少动态设置关闭重开仍保留。
- 拖动到左侧后保持首页；轻点进入原 AI；隐藏设置重启仍保留且 AI 入口可用。
- 原 AI 草稿收起恢复、发送、历史、记账导航通过；地图与时间线原测试通过。
- `--pet-reset` 仅在 DEBUG 且明确启用 Journey UI fixture 时生效，只重置示例用户的宠物设置。

## 发布边界

当前是已验收的开发改动，没有发布或更新真实设备。Android 原生桥未改，专项通过 Android UA + 受限桥的浏览器路径验证；后续 APK 发布仍应执行签名、设备安装及更新清单流程。

终止原因由新后端可选字段提供，旧客户端可忽略。旧服务器已经保存且未带标记的部分正文无法追溯完成原因；新客户端保留明确停止/错误文案回退。发布时需同步上线后端字段。
