合计：27 项 JVM 单元测试 + 6 项 Python/Node 脚本测试。

```bash
cd android
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease :app:assembleDebugAndroidTest
cd ..
python3 -m unittest discover -s android/tests -v
```

Release 使用 R8 与资源压缩。测试 APK 可编译，生产 APK 不打入 android-test.html；package-release.py 校验包名、版本、正式证书与 assetlinks 指纹、网页快照哈希。只生成本地文件，不调用发布脚本、不更新官网 latest。

最终构建结果：Gradle BUILD SUCCESSFUL；lint 为 0 errors（仍有既有样式/Manifest 和 Kotlin 便捷 API 建议类 warnings）；本地正式签名 0.12.0 (29) 已归档到 `android/releases/0.12.0-29/`，约 2.74 MiB。包名、版本、签名指纹、无 debug fixture 与网页资源校验均通过。构建体积是实际结果，不沿用最初方案的 10MB 估计。

## 可选设备用例（本轮不作为完成门槛）

`NativeInstrumentedTest.kt` 保留以下可运行测试：

1. 原生首页→聊天→追问→返回；无真实账号或业务数据写入。
2. 发送断网保留输入并可重新提交。
3. 深度/联网请求字段与停止操作。
4. 深色、1.3 倍字体、减少动态下保留草稿并看得见发送键。
5. 邀请码注册并加密保存凭证。
6. 同 origin 旧凭证迁移，加密存储、明文清理与退出后不复活旧 token。
7. 网页退出同步、旧网页不能覆写较新会话。
8. 伪造链接拒绝、邀请进入确认流程。

用户补充指令前的首轮运行：8 项中 4 项通过；4 项因 FAB 文本节点合并后的测试选择器未命中，未进入聊天。已把选择器改成稳定的 open-ai testTag 并编译通过，随后按用户要求关闭模拟器，**未复测，不记为通过**。原有 20 项 WebFallback/更新设备用例保留但本轮未跑完整回归。
