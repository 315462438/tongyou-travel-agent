## B. 线上手工回归（双账号）

1. **Copilot**：右栏点「减少步行」chip → 「🤖 AI 思考中…」→ 提案卡出现（改动列表带
   op 徽章 + 理由）→ 点改动条目左栏定位闪烁 → 采纳后行程变化、检查中心里程下降 →
   「恢复原样」回到之前；
2. **纯问答**：输入「Day1 这些地方哪个要预约？」→ 只有回答无采纳按钮；
3. **评论**：A 在「中央大街」发评论 → B 侧 ≤3s 卡片 💬 计数变化，展开可见、可回评，
   B 删不掉 A 的评论；
4. **Presence**：B 停在 Day2 → A 侧 B 头像绿圈 + D2 角标；B 关页 10s 后绿圈消失；
5. **修改记录**：右栏展开「🕘 修改记录」——双方的增删改、AI 提案采纳都有留痕；
6. **真实交通时间**：选中天的卡片之间出现「↓ 步行 12 分钟 · 0.9km」；给条目改交通方式
   为「驾车」后段间时间按驾车重算；
7. **AI 起草护栏**：非空行程再点 AI 起草 → 不再直接覆盖，而是出提案（消息含 proposal）。
