## 五、人工验收（部署后）

1. 侧栏「连接」→ 面板列出三项，携程显示「未连接」+「下次查酒店时会引导你扫码连接」
2. 走一次查酒店流程并扫码 → 回到面板应显示「已连接」+ 相对时间
3. 点「断开并清除登录态」→ 二次确认文案里必须提到**会清除其他站点登录**
4. 断开后服务器上 `/home/ubuntu/chrome-agent-profiles/{user_id}` 目录应不存在
5. 水墨主题下面板配色正常（全部走 token，未硬编码颜色）

## 六、独立扫码连接（第二期）

| # | 用例 | 期望 | 自动化 |
| --- | --- | --- | --- |
| 14 | 同用户互斥 | 连点两次返回同一个 token，只起一个后台任务 | `test_same_user_cannot_open_two_sessions` |
| 15 | 结束后可重试 | 超时/失败的会话不占用，再发起换新 token | `test_finished_session_can_be_restarted` |
| 16 | 不同用户互不影响 | token 不同 | `test_different_users_are_independent` |
| 17 | 取消不被超时覆盖 | `cancelled` 不会被后台改回 `timeout` | `test_cancel_is_not_overwritten_by_timeout` |
| 18 | 但成功可覆盖取消 | 已扫码成功以事实为准 | `test_cancel_does_not_block_a_successful_login` |
| 19 | 截图地址只在 waiting 暴露 | 其余态为空串 | `test_screenshot_url_only_exposed_while_waiting` |
| 20 | token 不是 user_id | 32 位随机，用完即弃 | `test_screenshot_token_is_not_the_user_id` |
| 21 | 超时短于轮次内 | `connect_wait_s < handoff_wait_s` | `test_connect_wait_is_shorter_than_in_turn_handoff` |
| 22 | 内置连接器不能发起 | 400 | `test_builtin_connector_cannot_start_connect` |
| 23 | 无会话返回 idle | 200 + `state=idle`，不是 404 | `test_status_returns_idle_not_404` |

> 用例 20 的理由：截图那条路由**故意不鉴权**（`<img>` 带不了 header，同 Phase 5）。
> 拿 `user_id` 当 key 的话，那是长期标识，泄露一次就长期可探测；每次会话新生成的
> token 用完即删文件，窗口 ≤ `connect_wait_s`(90s)。

> 用例 21 不是凑数：轮次内的 180s 砍不得（砍了整轮就废），独立流程砍得（失败可重试）。
> 这条断言把「为什么要独立出来」变成可执行的约束。

## 七、「包含的操作」与真实能力对账

| # | 用例 | 期望 | 自动化 |
| --- | --- | --- | --- |
| 24 | 小红书操作 == 只读白名单 | 相等（不是包含） | `test_xhs_operations_match_the_readonly_whitelist` |
| 25 | 当前无写操作 | 全部 `write=False` | `test_no_connector_declares_a_write_operation` |
| 26 | 高德操作在代码里真有 | `hasattr(amap, tool)` | `test_amap_operations_exist_in_code` |
| 27 | 前端如实渲染 | `conn-ops` + 条件 + tool 名 | `连接面板：「包含的操作」列出真实工具名` |

> 用例 24 是这套东西里最有价值的一条。`xhs_mcp._READONLY_TOOLS` 是 Phase 68 的安全
> 边界（该 MCP 还暴露发帖/评论/点赞，登录态是共享运维账号），连接器页面是它的
> **用户可见投影**。断言相等而非包含，两个分叉方向都拦：白名单放宽了页面没跟上
> （用户看到的范围是假的）、页面写了白名单没有的（承诺做不到的事）。
>
> 用例 25 是给未来的：哪天真要加写操作，这条会红——那时必须先想清楚授权模型
> （谁的账号、能撤销吗、误操作怎么办），而不是顺手加个 `Operation`。
