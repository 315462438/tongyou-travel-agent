## 自动化用例

| 编号 | 场景 | 断言 |
| --- | --- | --- |
| A1 | 热门封面输入清洗 | 多城取首城、去重、跳过空值、最多 4 个 |
| A2 | 封面第三方异常 | 单个城市失败不影响其他结果，接口仍返回 200 语义 |
| A3 | 成功与空结果缓存 | 同一城市二次请求均不重复调用高德 |
| A4 | 真实热门顺序 | 卡片数据由 onboarding 近 30 天统计构造，无数据才使用目的地兜底 |
| A5 | 单入口短地名 | “阿勒泰”套旅行预演模板 |
| A6 | 单入口普通问题 | “日本签证怎么办”原样交给后端自动路由 |
| A7 | 链接与预算分流 | 公开链接走收藏整理；空目的地+出发地+预算走预算推荐 |
| A8 | 唯一输入契约 | 空状态不渲染第二个 Composer 或自由提问展开按钮 |
| A9 | 图片代理 | 外图 URL 经 `/api/img?u=` 同源加载，失败保留渐变占位 |
| A10 | 卡片布局 | 桌面四列，移动端横向滚动并启用 scroll snap |
| A11 | 卡片选择 | 点击只执行 `setIdea(city)` 回填主输入，不直接创建会话 |
| A12 | 减少动态效果 | reduced-motion 下关闭卡片入场、悬浮位移和图片缩放 |
| A13 | 品牌视觉融合 | 标题固定中文粗黑字体栈；输入框常态蓝紫光边；局部柔光呼吸可被 reduced-motion 关闭 |
| A14 | 标题颜色波动 | 主标题使用连续深蓝—靛紫—玫紫渐变慢速往返；reduced-motion 下固定位置 |

## 人工走查

| 编号 | 步骤 | 期望 |
| --- | --- | --- |
| M1 | 登录后新建对话 | 只看到一个主输入；标题为深色，顶部仅有局部柔光，无全屏彩幕 |
| M2 | 等待热门数据加载 | 展示近 30 天前四目的地；封面逐步出现，不阻塞输入 |

| M6 | 粘贴公开攻略链接 | CTA 变为“整理成行程”，当前请求打开深度推理 |

| M10 | 低高度桌面视口 | 保留截图中的标题、输入框光边和背景柔光，同时首屏底部能看到热门卡片区域入口 |
