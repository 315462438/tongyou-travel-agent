## 自动化用例

```bash
cd frontend
npm test
npm run lint
npm run build
```

## 手工验收

1. 打开接力站，第一屏先看到“最近大家都想去”及四张目的地卡；
2. 榜单有真实数据时显示“近 30 天真实热问”，失败回退时显示“本期旅行灵感”；
3. 图片加载成功时显示真实景点封面，失败时显示渐变品牌占位，不出现破图；
4. 点击任意热门卡，当前目的地和动态列表同步切换；
5. 搜索框位于推荐卡之后，聚焦时只有柔和渐变光圈，不出现黑色原生矩形；
6. 输入“冰岛”按 Enter，仍可进入任意目的地；
7. 开启系统“减少动态效果”后 Aurora 和卡片入场动画关闭；
8. 手机端横滑热门卡，搜索框和发布按钮不溢出。
9. 在 1920px 高分屏上，作者时间、阶段标签、有效期、筛选和反馈按钮无需放大页面即可阅读。
