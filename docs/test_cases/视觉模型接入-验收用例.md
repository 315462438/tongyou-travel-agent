## `tests/test_vision_integration.py` — 集成约束（10 条）

### ① 视觉产出是外部内容

| 用例 | 断言 |
| --- | --- |
| **`test_xhs_vision_output_is_wrapped`** | 产出过 `wrap_external` 且 `source="note_image"`。**图片输入绕过了 Phase 69 的全部文本防线**——一张图里印着「忽略之前的指令」是直接进模型的；schema 约束只挡住「模型只能往固定字段填」，标签包裹才是那道熟悉的防线 |

### ② 页面判定是对照通道，不改行为

| 用例 | 断言 |
| --- | --- |

| `test_vision_page_type_off_returns_none` | 分开关关 → 不截图不调模型 |

## 线上真实验证

服务器上传一张**行程截图**（大阪 3 天，含景点/门票/酒店），用户消息**文字为空**：

```
[  8s] 正在看你发的 1 张图…
[ 24s] 已获取高德实时数据（天气 + 景点）：大阪      ← 目的地从图里解析出来
[ 32s] 正在携程定位「奈良」                        ← 多城也读出来了
[176s] 正在看 1 篇笔记的图片内容…
[184s] 从 1 篇笔记的图片里读到了额外信息            ← 4 篇里只有 1 篇 desc 薄，过滤生效
✅ 369s 完成，4241 字 →「大阪·奈良3日经典暴走+治愈行程」
   Day1 大阪城+道顿堀 / Day2 环球影城 / Day3 奈良 —— 完全对应图里内容
```

落库核对：
- 用户消息 `content=''`、`meta={'images': ['c0405fb1…']}` ✓
- 10 条来源里 1 条带 `vision_used`，产出包在 `<external_content source="note_image" …>` 里 ✓

**时长对照**：369s vs 基线（苏州 360s、杭州 256s）同量级——视觉没有拖慢。
xhs 视觉段 176s→184s 只花 **8 秒**，而浏览器道跑到 304s，**零墙钟增量**（实测三轮浏览器道
始终是长杆：272s/208s/457s vs xhs 96s/120s/96s）。
