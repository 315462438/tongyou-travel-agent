## 八、手工验收（线上/本地跑通链路）

1. 生成一份 3 天以上、结尾带预算表的攻略。
2. 点「🎨 生成手账海报」→ 正常出图；点「💰 预算明细」→ **明显更快**，且预算表里
   结尾章节的条目**不再缺失**。
3. 核对海报上的地点与预算明细里的条目：同一天的项目应当对得上。
4. 点「导入行程板」→ 秒级完成，地点与海报一致。
5. 多轮修改攻略后重复 2-4：面板内容应随新正文更新（不是旧对象图）。
