### 后端 `tests/test_support_online.py`

| 用例 | 断言 |
| --- | --- |
| A1 在线窗口内 | `last_seen` 距今 < `online_window_s` → 在线 |
| A2 窗口外 | 超过阈值 → 离线 |
| A3 从未活跃 | `last_seen_at` 为 NULL **不算在线**（存量用户不能被伪造成活跃） |
| A4 naive 时间不炸 | Postgres 取回的 naive datetime 与 aware 相减不得 TypeError（会打挂**整个鉴权**） |
| A5 首次 touch | 从未活跃的用户被访问后写入 `last_seen_at` |
| A6 节流生效 | 距上次不足 `online_touch_throttle_s` **不得再写库**（鉴权是最热路径，写放大） |
| A7 超窗口再写 | 超过节流窗口后正常更新 |
| A8 用户发消息 → admin 未读 | 未读数 1，摘要与发送方正确 |
| A9 admin 读取即已读 | 读完 `unread_total` 归 0 |
| A10 admin 回复 → 用户未读 | 用户侧未读 +1 |
| A11 用户读取即已读 | 读完用户侧未读归 0 |
| A12 未读对称 | **自己发的消息永远不算自己的未读**，两个方向都成立 |
| A13 会话隔离 | A 只看得到自己的消息 |
| A14 回复不存在的用户 | 404 |
| A15 空消息 | 400 |
| A16 超长消息 | 截断到 `support_message_max_chars` |
| A17 无消息时 | 列表为空且不报错 |
| A18 列表带在线标记 | thread 里 `online` 正确 |

另：`tests/test_agent_api_auth.py` 的 AST 全量路由扫描必须继续通过 —— 6 条新路由
全部带鉴权，**不得**进 `PUBLIC_ROUTES`。

### 前端

| 用例 | 断言 |
| --- | --- |
| B1 相对时间分档 | `formatLastSeen`：从未活跃 / 刚刚 / N 分钟前 / N 小时前 / N 天前 / 很久以前 |
| B2 客户端时钟偏差 | 服务端时间略快于本机时显示「刚刚」，不得出现「-1 分钟前」 |
| B3 带时区的 ISO | `+00:00` 的时间戳换算正确（后端 `iso_utc` 保证） |

| B5 入口与徽标 | 侧边栏「联系客服」红点、admin 标签页未读徽标、`AdminSupport` 已挂载 |
| B6 轮询不重复 | 抽屉打开时暂停未读轮询 |
| B7 输入法 | 回车发送但不打断中文候选词确认 |
| B8 Esc 优先级 | Esc 先关客服抽屉，再关 admin 面板 |

## 人工走查

前置：两个浏览器（或一个用无痕），分别登录 **admin** 与一个**普通用户**。

| 用例 | 步骤 | 期望 |
| --- | --- | --- |
| M1 在线点亮 | 普通用户登录并操作 → admin 打开「用户管理」 | 该用户前面是绿点，右侧显示「在线」；顶部「共 N 位 · M 人在线」 |
| M2 离线衰减 | 普通用户关闭页面，等 5 分钟以上，admin 面板停留（30s 自刷新） | 绿点熄灭，变成「N 分钟前」 |
| M3 存量用户 | 看从未登录过的老账号（如 `alice`） | 显示「从未活跃」，**不是**「刚刚」 |
| M4 用户提问 | 普通用户点侧栏「联系客服」→ 发一条消息 | 消息以紫色气泡出现在右侧 |
| M5 admin 收到 | admin 面板「客服会话」标签 | 出现红色未读徽标；列表里该用户有未读数与摘要 |
| M6 admin 回复 | 点进会话 → 回复 | 用户侧 30s 内出现红点；打开抽屉看到灰色气泡回复 |
| M7 已读归零 | 用户打开抽屉读完后关闭 | 侧栏红点消失 |
| M8 不串号 | 用第二个普通用户发消息 | 两人各自只看得到自己的会话 |
| M9 移动端 | 手机模式：抽屉打开侧栏 → 联系客服 | 气泡单列、输入框贴底可用，不被遮挡 |
| M10 长文本 | 粘贴一大段（>2000 字） | 正常发送，服务端截断，不报错 |

## 边界（明确不做）

- 无实时推送，靠轮询：admin 回复到用户看见最长 30s（抽屉关着时）。
- 无工单状态流转、无附件、无自动回复。
- 用户开着页面但完全不操作时，仍有会话列表/未读轮询，故一般仍判在线；
  完全静置且无任何轮询才会掉成「N 分钟前」。
