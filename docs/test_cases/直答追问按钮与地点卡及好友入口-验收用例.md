## 手工验收（部署 / 装机后）

1. 开联网搜索问「合肥洗浴中心推荐」：回答下面出现地点卡（横滑），再下面是 2-3 个追问按钮。
2. 点追问按钮：等同发送该句；新回答生成时旧按钮消失。
3. 地点卡点「导航」：唤起高德；点「加入行程」：选一个行程 → 提示已加入 → 行程第 1 天出现该地点且有坐标。没有行程时「新建一个行程」可用。
4. 「我的」第一行「好友」：搜索用户名 → 加好友；另一账号看到角标 → 接受；双方列表出现对方。页面里没有接力站。
5. iOS、网页、安卓各走一遍 1-4。
