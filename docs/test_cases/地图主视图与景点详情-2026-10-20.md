## 执行命令
```sh
cd backend && .venv/bin/python -m pytest tests/test_place_details.py tests/test_trip_collab.py -q
cd frontend && npm test && npm run build
PLAYWRIGHT_MODULE=/tmp/tongyou-qa/node_modules/playwright/index.mjs node frontend/tests/trip-route-browser.mjs
PLAYWRIGHT_MODULE=/tmp/tongyou-qa/node_modules/playwright/index.mjs node frontend/tests/journey-browser.mjs
xcodebuild -project ios/Tongyou.xcodeproj -scheme Tongyou -configuration Debug -destination 'platform=iOS Simulator,id=3CC65BBB-8959-4212-BDB1-7EF0DF536B30' -derivedDataPath /tmp/tongyou-journey-build -only-testing:TongyouUITests/JourneyUITests CODE_SIGNING_ALLOWED=NO test
JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-21.jdk/Contents/Home python3 android/scripts/test-emulator.py --serial emulator-5554
```
各命令在对应目录或项目根目录执行。浏览器 API/地图 SDK 使用内存替身，iOS/Android 使用 DEBUG 夹具，不写生产业务数据。地图截图不能用于证明真实地图瓦片可用性。
