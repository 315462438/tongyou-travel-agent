# Phase 41 验收用例 — 多人记账本（AA + 一键结算）

对应自动化测试：`backend/tests/test_trip_collab.py`（新增 3 例，共 25 例）。
设计见 `docs/task_plans/task_plan-phase41-多人记账本.md`。

## A. 自动化

| # | 用例 | 预期 |
| --- | --- | --- |
| A1 | 结算算法 | 三人混合分摊（含部分人参与账目）：per_person 垫付/应摊/差额正确；转账金额守恒且为最小笔数 |
| A2 | 容错与精度 | 金额≤0 / 无参与人的账目忽略；除不尽保留两位小数 |
| A3 | API 全流程 | 记账默认全员摊、可指定参与人；负数金额 400；summary 的 total/差额/转账/文字账单正确；只能删自己的（owner 例外） |

## B. 线上手工回归（双账号）

1. A 记「晚餐 ¥300 餐饮 全员」，B 记「门票 ¥120 只 bob」→ 双方 ≤3s 都能看到两笔流水；
2. 预算面板出现「已记账实际支出 ¥420」（超预算变红）；
3. 点「💰 一键结算」→ 弹窗：分类小计 chips、每人垫付/应摊/差额表格（应收绿/应付红）、
   「💸 bob → alice ¥150.00」转账卡片；
4. 「📋 复制文字账单」→ 粘贴到微信是可读的结算文本；
5. B 删不掉 A 记的账（按钮只在自己的账目上出现）；修改记录里有「记了一笔/删除了账目」。

## 设计要点备忘

- 结算是**确定性算法**（Splitwise 式贪心最小转账），零 LLM 成本、结果可复现；
- 参与人快照存账目行内（成员后续退出不影响历史账目的分摊计算）。
