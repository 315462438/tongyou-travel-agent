## B. 线上手工回归

1. **三栏布局**：打开任一行程——左 Timeline（按天分节、卡片带时间/停留/交通/门票/标签徽章）｜中 Day 标签 + 静态路线图（编号与卡片一致、颜色分天）｜右 AI 面板（预算/检查中心/AI 按钮/点评），**无空白栏**；
2. **编辑弹窗**：卡片 ✎ → 填到达时间/停留/交通/门票/标签 → 保存后卡片徽章更新，门票合计变化；
3. **检查中心**：设预算 100 + 给两个点填冲突时间 → 出现预算/时间冲突 issue；点击 issue → 左栏对应卡片滚动到位并闪紫框；设出发日期后如目的地近日有雨 → weather 告警；
4. **地图联动**：点左栏 Day2 的卡片 → 中栏自动切到 Day2 地图；
5. **对话联动**（用户特别要求）：
   - 对话里点「导入协同行程」→ 板头出现「📄 来源对话」→ 点击回到原对话且攻略可见；
   - 回到该攻略消息：按钮已变为「🗺️ 打开协同行程」→ 点击直达同一块板；
6. 窄屏（<900px）三栏转纵向堆叠、地图置顶。

## 已知边界

- 静态图单天 >10 点截断展示（有提示）；时间冲突检查仅在两条目都填时间时生效；
- 天气检查覆盖出发日起 4 天（高德预报上限）。
