# Phase 32 验收用例 — 调用链面板重设计（左树右详情）

纯前端改造（后端 /trace 接口未动），无自动化基建，以下为手工验收清单。
设计见 `docs/task_plans/task_plan-phase32-调用链面板重设计.md`。

## 手工验收（线上）

| # | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| 1 | 树层级 | 打开一轮深度研究的「🔗 调用链」 | 左栏观测树：TRACE 根 → CHAIN/AGENT 嵌套 → GEN/TOOL 叶子，缩进正确、总条数显示在树头 |
| 2 | 折叠 | 点行首 ▾/▸ | 分支折叠/展开，点击行其余区域是选中不是折叠 |
| 3 | 徽章配色 | 观察各类型 | TRACE 紫 / CHAIN 蓝 / AGENT 靛 / GEN 绿 / TOOL 红 / SPAN 灰 |
| 4 | 时间条 | 观察每行名字下的细条 | 位置=相对开始时刻，长度=相对耗时；LLM 调用（GEN）明显是大头 |
| 5 | 详情面板 | 点任一 GEN 节点 | 右栏：徽章+名称+模型+耗时；tokens 用量；输入/输出 pretty JSON、面板内滚动，不撑坏左树 |
| 6 | 截断 payload | 点一个超长输入的节点 | 显示原文（带「…(截断)」尾巴），不因 JSON 解析失败而报错 |
| 7 | 空态三连 | 未启用埋点 / 无该轮记录 / langfuse 挂了 | 分别显示对应提示文案（与旧版一致） |
| 8 | 窄屏 | 浏览器缩窄 <720px | 树与详情转为上下布局，均可滚动 |
| 9 | guide/direct 轮 | 打开一轮普通攻略的调用链 | 结构同样清晰；Phase 31 后 GEN 节点的输入应显示标准消息数组（assistant.tool_calls / tool 角色可辨） |
