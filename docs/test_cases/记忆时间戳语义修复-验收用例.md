## 迁移（线上验证清单）

1. 重启后端 → 日志出现 `applying schema changes`，含 `travel_memory.last_used_at`；
2. `select count(*) from travel_memory where last_used_at is null` → **0**；
3. 抽查此前偏差最大的行：`updated_at` 应回落到 `created_at`，`last_used_at` 保留原「最后注入」值；
4. 再次重启 → 日志 `schema is up to date, skipping DDL`，且三个时间**无变化**（回填不重复生效）；
5. 打开记忆面板 → 三个时间分别显示，活跃用户的「建立」不再是「今天」。
