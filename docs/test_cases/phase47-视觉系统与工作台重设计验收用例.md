# Phase 47 — 视觉系统与旅行工作台重设计验收用例

## 自动化验证

```bash
cd frontend
npm test
npm run lint
npm run build
```

### TC-47-01 攻略目录解析

- 只提取 Markdown 二、三级标题；
- 标题清除强调符号并生成稳定锚点；
- 最多返回 12 项，避免超长攻略目录反过来挤占正文。

对应自动化：`frontend/tests/interaction-utils.test.mjs`。

## 手工视觉与交互验证

### TC-47-02 首页工作台

1. 桌面首页显示四张任务卡，包含用途、预计耗时和能力类型；
2. 点击普通任务填入输入框，点击“帮我做选择”同时开启深度推理；
3. 390px 视口改为单列任务卡，无横向滚动，输入区仍可达；
4. 颜色、圆角、阴影与侧栏保持一致。

### TC-47-03 长攻略与消息操作

1. 含至少两个二/三级标题的回复显示“本篇目录”；
2. 点击目录项平滑滚动到对应标题；
3. 复制、调用链、生成海报、导入/打开行程位于统一操作栏；
4. 普通短回复不显示目录，流式回复不提前显示操作栏。

### TC-47-04 管理抽屉

1. 桌面端记忆、技能、用户管理从右侧滑入并占满可用高度；
2. 点击遮罩或 Escape 可关闭；
3. 560px 以下改为底部 Sheet，并避让底部安全区；
4. 列表滚动不带动背后主页面。

### TC-47-05 协同行程桌面布局

1. 标题栏只展示返回、标题/目的地、状态、成员与行程操作；
2. 来源对话、分享和邀请出现在“行程操作”菜单；
3. AI 上下文栏可折叠为窄边，再次点击恢复；
4. 地图和时间线在 AI 栏折叠后获得更多空间；
5. 小于 900px 时隐藏桌面折叠按钮，继续使用三段切换。

### TC-47-06 视觉回归防护

- 首页 eyebrow 文本不受旧渐变裁剪影响，不能显示为空白胶囊；
- 行程操作菜单位于三栏内容之上；
- 菜单打开期间隐藏折叠 AI 栏的“展开/收起”控件，关闭菜单后恢复。

对应自动化：`frontend/tests/visual-regressions.test.mjs`。
