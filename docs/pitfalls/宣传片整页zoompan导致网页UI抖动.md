# 宣传片整页 zoompan 导致网页 UI 抖动

## 现象

对网页端产品截图使用持续 `zoompan` 后，正文、细线边框和卡片圆角会出现轻微抖动。观看者会误以为页面本身不稳定，尤其在 1080p 的横屏成片中更明显。

## 原因

整页缩放让文字和 1–2px 边线不断落在不同的亚像素位置；视频编码再次采样后，边缘锐度会逐帧变化。即使缩放幅度很小，也会在静态 UI 上形成“呼吸式抖动”。

## 解决办法

- 网页主体保持 1920×1080 原生尺寸，不再使用整页 `zoompan`。
- 动态感交给输入状态、阶段推进、流式内容、抽屉和模块切换。
- 大章节采用横向卡片翻转，转场时才改变画面几何；阅读阶段完全稳定。
- 验收时在同一静态场景抽取相隔 1 秒的两帧，以 PSNR ≥ 60dB 作为无可见抖动的自动门槛。
