# 账户页面不能盖住工具弹层

## 现象与原因
Android / Web“我的”点击公告、用户管理等看似无响应，点“完成”后才出现。账户页固定定位 z-index:60，通用 modal-mask 仍为 50，入口函数已执行、数据也可能已加载，但新面板被旧页面覆盖。仅用 DOM 存在或 isVisible 无法发现遮挡。

## 修复
journey-shell 直接子级的全局 modal-mask 统一为 z-index:240，高于账户、导航、AI 和历史。不改行程内部弹层，不修改 iOS。工具开启时账户 inert，阻止背景键盘操作；关闭后恢复原页和“更多工具”展开状态。补齐连接面板 Escape 分支。

## 验证经验
account-panels-browser.mjs 修复前第一项公告的 elementFromPoint 命中检查即失败；修复后覆盖六个入口、点击关闭与 Escape/Android 返回、重复打开、管理员与普通用户。不点击“完成”，不使用 force 点击绕开遮挡。
fixture 的 admin/users 必须返回 {total,users}，不能返回数组，否则会触发组件异常，与遮挡无关。Android Java fixture 新增 JSON 字符串转义调用需使用完整 org.json.JSONObject 类名（文件原本没有 import）。
