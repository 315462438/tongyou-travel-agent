# 复用头像组件也要区分展示密度

日期：2026-08-11（Phase 85）

## 现象

同一张头像在个人主页大图中显示正常，但放到深色侧栏的当前用户卡片后，主体细节不完整，用户会
直观认为图片被裁掉。

## 原因

组件复用的是同一个 `Avatar`，但侧栏沿用了 36px 默认尺寸与 `object-fit: cover`。对于主体靠近
边缘、包含装饰边框或本身已经做过圆形构图的头像，小尺寸再次 cover 会损失有效内容；即便裁切
比例相同，小尺寸的视觉损失也会明显放大。

## 解决办法

- 侧栏身份入口使用更大的独立头像规格，不改变全局默认值；
- 对该入口采用 `object-fit: contain` 和居中定位，优先保证主体完整；
- 用边框与背景补足 contain 可能产生的边缘留白；
- CSS 必须限定在 `.social-me-mini` 下，避免改变好友列表和主页头像设计；
- 用源码级视觉回归测试锁定尺寸和裁切策略。

## 结论

头像组件可以共用，但不同信息密度的入口不能盲目共用同一尺寸和裁切策略。导航身份入口应优先
保证“能认出是谁”，内容流头像才更适合强调铺满与紧凑。
