# 调色阶不等于换掉整体色彩印象

## 现象

首轮把旧蓝紫描边改成松绿、把黄褐中性色稍微降饱和后，代码和色值确实变化了，
但上线截图仍被用户判断为“还是这个颜色”。

## 原因

整体色彩印象由大面积背景、主行动色、深色大块和强调色共同决定。只微调明度或删除冲突色，
如果仍保留相同的主色相（松绿）、纸张底色（暖黄）和深色横幅（绿褐），用户感知到的仍是同一套风格。

## 解决办法

- 先明确是在做“同风格精修”还是“更换视觉风格”；
- 需要换风格时，同步更换中性色温、主行动色、深色大块和阴影色，不只改一个边框；
- 用上线全屏截图判断大面积色块占比，不能用 token 数量或局部色差代替视觉结果；
- 保留兼容 token 时，新增真正的主色 token，并让旧名字显式指向它，避免实现与文档继续误导。
