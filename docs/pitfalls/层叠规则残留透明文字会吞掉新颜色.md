# 层叠规则残留透明文字会吞掉新颜色

## 现象

将首页眉题从渐变文字改为普通文字时，新增了 `color: var(--x-text-3)`，但页面上文字仍可能消失。

## 原因

原渐变文字规则依赖 `color: transparent` 让背景渐变透过字形。改造时只删除了
`background-clip: text`，却留下同一规则块中位置更靠后的 `color: transparent`；由于声明顺序，
它会覆盖前面的新颜色。设计意图正确，但最终 computed style 仍是透明。

## 解决办法

- 从基础 `.hero-eyebrow` 规则中删除残留的 `color: transparent`；
- 视觉回归测试直接断言该规则块不再包含透明文字色；
- 今后移除渐变文字时，要把 `background`、`background-clip`、`-webkit-text-fill-color`、
  `color: transparent` 作为一组一起检查，不能只改其中一项。
