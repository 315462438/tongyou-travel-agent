# 深色文字覆盖还需处理透明填充与玻璃背景

现象：AI 夜间标题仍为暗蓝色，输入标签、正文及辅助提示偏黑；手机网页的白色玻璃渐变在深色下依旧生效。

原因：旧首页颜色来自只适用于浅色的 x-n token；标题设置了 `-webkit-text-fill-color: transparent` 和裁切渐变，单独覆盖 color 无效；MobileGlass 又用独立浅色背景覆盖了卡片。Android 选择器更具体，通用占位符颜色也会被覆盖。

解决：在 JourneyShell 的 AI 工作区限定范围，文字、按钮、卡片共同使用外观语义色；标题恢复 currentColor 填充；卡片移除旧背景渐变。以足够的选择器优先级覆盖移动端，不改尺寸与排版。

验证注意：仅看 computed color 会漏掉透明文字填充；仅计算 backgroundColor 会忽略 backgroundImage。回归同时检查实际 text fill、占位符透明度、卡片无旧渐变，并人工检查明暗截图。浏览器 color-mix 可能返回 color(srgb ...)，测试用 canvas 转换，不用仅适配 rgb() 的正则。
