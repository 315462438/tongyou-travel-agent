# 行程地图同屏与旧移动样式覆盖

## 现象
地图从 tab 移到同一页后，安卓页面仍不显示地图；深色模式地图标题残留白底。iOS 隐藏系统 tabBar 后自定义主导航仍遮住详情底部。

## 原因与解决
- Android 原有 `.trip-3col > .trip-col-map` 隐藏规则有更高优先级，且地图 JSX 仅在 map tab 挂载。删除互斥挂载，使用同屏工作区限定的覆盖规则；浏览器检查真实可见矩形，不能只检查 DOM 存在。
- 旧地图头部有独立白底。明确继承主题文字与透明背景，检查浅深色截图。
- 自定义 JourneyDock 不受 `.toolbar(.hidden, for: .tabBar)` 控制。按 Home NavigationPath 的深度隐藏详情中的 Dock，返回根页面后恢复；不在详情 onDisappear 上清标记，避免推入群聊时错误恢复导航。
- 地图先过滤无坐标地点再编号会造成编号不一致。先按完整当天列表编号，再筛选有坐标地点；自动化含中间缺坐标的 1/2/3 测试数据。
- 选中发生在地图 SDK 就绪前会丢失焦点。焦点 effect 同时依赖地图就绪和内容签名；全览清空选中并适配全部点位。

- 地图 SDK loader 的并发等待队列在首次请求失败时不会 reject，React StrictMode 重挂载恰好触发，单纯忽略已卸载组件的错误会留下空白图。共享首次加载 Promise，并加 12 秒回退上限；失败用例阻断 SDK 与静态图后检查可见提示及列表编辑。
