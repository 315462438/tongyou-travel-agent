# 主题切换必须覆盖品牌图标

## 现象

现代主题与水墨主题切换时，页面背景、标题和按钮都会变化，但侧栏左上角的路线品牌图标始终保持朱砂红，造成主题切换不完整。

## 原因

品牌图标使用了固定的 `--x-cinnabar` 背景；水墨主题的覆盖值也是同一个颜色。虽然选择器命中了图标，两种状态的最终颜色却相同。

## 解决办法

- 默认 `.brand-mark` 使用现代主题的皇家蓝 token；
- `.theme-ink .brand-mark` 单独覆盖为朱砂印色；
- 自动化测试同时断言默认值和水墨覆盖值，避免只检查“存在主题选择器”却漏掉两种主题视觉结果相同的问题。

## 后续约束

双主题组件必须对比两个主题的最终语义值。仅存在主题覆盖规则，不代表视觉上真的发生了切换。
