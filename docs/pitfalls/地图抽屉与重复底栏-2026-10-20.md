# 地图抽屉与重复底栏

## 原生底栏叠加
现象：iOS 记账页显示系统 TabBar 和自定义 JourneyDock 两层导航。仅在子页面隐藏系统栏，不能保证 NavigationStack 切换后仍隐藏。
解决：移除 TabView，根容器只创建一份 JourneyDock。持久页面按当前 tab 控制透明度、命中测试、可访问性，并把当前页面提高 zIndex；AI 面板关闭时置于底层，保留草稿和对话状态。
验证：三根页切换、账本进入与返回、AI 打开/收起后恢复；断言系统 tabBars 为零，自定义入口唯一。注意多个 NavigationStack 的隐藏层仍可能出现在 XCTest 的底层树中，点击特定页面的导航栏，不能取全局第一个返回按钮。

## 抽屉手势与地图遮挡
现象：把整个手柄设为 pointer capture，会吞掉里面展开按钮的 click；旧地图 width 规则导致横屏地图浮钮伸进右侧抽屉。
解决：按钮不参与手柄 capture；地图直接作为 board 子元素并清除旧宽度/外边距；横屏左右分栏。ResizeObserver 按抽屉高度更新地图 fit padding，让路线位于可见区域。列表自己滚动，只有手柄触发切档。
验证：320px 窄屏、横屏、按钮切档、真实指针拖动、减少动态、地图失败仍可编辑。

## 景点资料降级
名称相同不代表地点相同；照片必须同时通过名称匹配、3km 坐标校验和图片域名白名单。海外/无坐标不误用国内同名照片。公共缓存不包含私密行程说明；provider 错误不缓存，避免“重试”一直命中错误。
React StrictMode 会重启请求 effect。失败重试测试需保持接口失败直至用户点击重试，不能只令第一条 HTTP 请求失败，否则第二次 effect 直接成功。
