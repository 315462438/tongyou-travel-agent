# 地图避让方向与移动卡片点击范围

## 地图偏移、缩放很远
AMap setFitView 的 avoid 参数顺序是上、下、左、右，不是 CSS 的上右下左。旧代码把面板高度传到左边。改为 [65, panelHeight + 20, 28, 28] 并限制底部高度；聚焦和全览共同使用，ResizeObserver 跟随面板。
参考：https://a.amap.com/jsapi/static/doc/20230922/index.html

## 全览后右侧空白
地图头部 inherited width:100%，叠加 left/right:14px 越界。点击右侧按钮会让 overflow:hidden 容器发生内部滚动，地图 x 变成 -14。清除固定宽度，自动化比较父子 x/width。地图点击改为仅滚动内部行程列表。

## 模拟 SDK 不代表真实底图可用
协议 mock 可以验证参数，不能验证地图投影与网络。localhost 的真实样式接口返回 HTTP200 JSON INVALID_USER_DOMAIN，SDK 把它当 protobuf 解码报 Unimplemented type。必须在允许的正式域名验证，业务 API 仍使用 fixture；等待真实样式与 tile 成功，再截图核对。不能忽略控制台错误后宣称通过。

## iOS 玻璃卡片留白点击无效
账本卡片 label 内只有文字参与命中，UI 测试点击卡片中部留白不能导航。添加 contentShape(Rectangle()) 覆盖整张卡片即可。不是隐藏 NavigationStack 的问题；不要因此重建根视图而丢失状态。
