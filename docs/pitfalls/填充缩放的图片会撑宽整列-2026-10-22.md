# SwiftUI 填充缩放的图片会把整列撑出屏幕

**现象**：iOS 攻略正文左右贴着屏幕边，表格两侧被切掉，尽管 ScrollView 内容有 16pt 边距。

**原因**：`RemoteImage` 内部是 `Image.resizable().scaledToFill()`，外面套 `.frame(maxWidth: .infinity).frame(height: 200)`。
填充缩放按高度 200 等比放大后的宽度比屏幕宽，`maxWidth: .infinity` 的弹性框接受了这个更大的宽度并上报给父级 VStack，
整列（包括所有文字段落）跟着变宽、居中后两侧溢出。

**解决**：先用 `Color.clear.frame(maxWidth: .infinity).frame(height: 200)` 定死框，再把图片放进 `.overlay`，最后裁圆角。
overlay 不参与父级尺寸计算。

**一般化**：`scaledToFill` 的图片永远不要直接决定布局尺寸，放在 overlay / background 里。
