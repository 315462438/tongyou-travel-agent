# 高分屏下“精致小字”会直接变成不可读

日期：2026-08-10

## 现象

同游圈在开发样式中大量使用 7.5–10px 辅助字号，局部截图看起来信息层级丰富，但在实际桌面高分屏
和较远观看距离下，作者时间、阶段标签、有效期、反馈按钮和筛选数量都难以辨认。好友和个人主页也
沿用了同一套小字号。

## 原因

- 把“视觉克制”等同于“尽量缩小字体”；
- 只检查布局是否装得下，没有建立产品级最小字号；
- 辅助信息虽非正文，却承担状态、可信度和操作含义，不能按装饰文字处理；
- CSS 像素在高 DPI 截图和系统缩放下的观感与设计稿局部预览不同。

## 解决办法

- 社交页建立统一基线：说明/时间/标签 ≥11px，操作/筛选 ≥12px，正文 ≥14px；
- 当前接力正文使用 15px，作者名 14px，时间与反馈按钮 11–12px；
- 好友列表、个人资料、移动底栏同步调整，避免局部可读而跨页失衡；
- 用自动化样式回归固定关键选择器的最低字号；
- 后续通过留白、颜色和字重制造层级，不再依赖 8px 小字。

## 结论

小字不是高级感。旅行社交内容需要快速扫读，状态和操作文字必须优先保证可读，再讨论视觉密度。
