# 宠物概念预览的浏览器与布局检查

日期：2026-10-22

## macOS 沙箱下 Chrome 在启动阶段退出

现象：Playwright 能创建进程，但浏览器随即 SIGABRT，清理时出现 EPERM，尚未加载页面。

原因：受限执行环境阻止 Chrome 所需的系统进程行为，不是预览的 JavaScript 错误。

解决：通过正常的权限审查启动仅用于本地测试的独立无头 Chrome，不复用用户浏览器、账号或配置。

## 两种首页长度不同，切换时预览导航跳动

现象：只给舞台设较小 min-height，长封面首页仍会撑高，切到紧凑卡片时底部设计切换器上移。

原因：舞台最小高度小于实际最高的内容，两个设计的手机高度也不同。

解决：统一手机最小高度、为窄屏单独留足空间，并给外层舞台相同的最小高度；自动用例同时测量两个设计舞台的实际高度。设置展开仍允许内容自然增高，不增加内部滚动。

## 预览包装产物需要刷新

片段变更后须重新运行 render.py；已有目标文件需要 `--force`。测试必须在包装命令成功后执行，否则会检查旧版本。
