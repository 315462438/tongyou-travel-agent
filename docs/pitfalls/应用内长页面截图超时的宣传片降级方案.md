# 应用内长页面截图超时的宣传片降级方案

## 现象

应用内浏览器可以正常读取和操作线上 17同游 页面，但对长页面执行视口截图时，底层截图命令持续超时并关闭临时标签页。

## 原因

页面包含较多长列表、渐变和图片资源；应用内浏览器截图需要在一次命令中完成合成，超出当前截图链路的稳定耗时。继续重试可能影响素材一致性，也可能意外录入浏览器外围信息。

## 解决办法

- 用真实线上页面的 DOM 与现有功能结构确认分镜内容。
- 从项目品牌组件和真实旅行素材构建高保真移动端 UI 演示帧。
- 不提交新规划、不修改用户数据，不使用全屏系统截图。
- 保留可复现的 SVG 帧和 FFmpeg 构建脚本，之后如截图链路恢复，可逐帧替换而无需重做剪辑。
