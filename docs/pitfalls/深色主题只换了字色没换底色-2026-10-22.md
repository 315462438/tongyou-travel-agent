# 深色主题只换了字色没换底色（2026-10-22）

## 现象
电脑切到深色后，协同行程板的「返回 / 导出攻略 / 旅行账本 / 行程操作 / 群聊 / 让 AI 调整」、行程天数 ± 、
美食/住宿/记账等工具面板全部变成**白底浅字**，几乎看不见；地点说明、时间待定等灰字在深底上也偏暗。

## 原因
1. `TripRouteLayout.css` 在深色下把 `--trip-ink/--trip-muted/--trip-line` 接到了 `--journey-*`（浅字），
   但 `--trip-surface`/`--trip-surface-soft`/`--trip-accent-soft` 仍是 `--tx-*` → `--x-n100` 白底。**只换了一半。**
2. `TripWorkspace.css`（桌面行程板）整份写死浅色 hex（`#fff`、`#64748b`、`#475569`…），没有深色值。
3. 面板/胶囊另有写死的 `rgba(255,255,255,.8/.94)`。
4. **`:root` 里的派生变量已解析**：`--tx-surface: var(--x-n100)` 在 `:root` 就算成了白色，
   在子树里只改 `--x-n100` 不会让 `--tx-surface` 跟着变——派生变量必须在同一作用域逐个重新给值。

## 解决
- `TripWorkspace.css` 的 hex 换成角色变量 `--tw-*`（浅色值逐字不变），文件末尾给深色值。
- 深色下在行程板作用域内重新给 `--x-n*` 中性色阶、`--tx-*`、`--trip-*`、`--x-glass` 深色值；
  强调色改浅蓝 `#8bb6ff`（作文字可读，作底色配已翻转为深色的 `--x-n100` 字）。
- 同一份规则用脚本生成两遍：`@media (prefers-color-scheme: dark)` 与 `html.native-android[data-android-appearance=dark]`。
- 用 Playwright 遍历行程板各工具页/菜单，按 WCAG（正文 4.5、大字 3）计算每个文字节点对**实际叠加后背景**的对比度，
  修到只剩禁用按钮。

## 教训
做深色主题时**字色与底色必须成对切换**；检查办法是算对比度而不是看「有没有深色规则」。

## 同日第二处：AI 对话页

行程板修完后，AI 对话页在系统深色下出现同一类问题：面板背景跟 `--journey-bg` 变深了，但攻略正文、标题、列表、
表格、「接下来」续作卡、手机玻璃输入卡读的是 `:root` 已求值的 `--x-n*` / `--tx-*` / `--mobile-glass-*` 浅色值——
深底深字（对比度 1.34）和深底白卡。修法同上：在 `.app.journey-shell .ai-workspace` 作用域内把这些令牌整体换成深色值
（系统深色、安卓深色各一份），再单独处理两处「本来就该是白/浅灰」的颜色（开启态模式胶囊的白字、免责提示）。

**一般化**：全站只有局部做了深色时，每个新的局部都会重演一遍。深色要么在 `:root` 层统一翻转，要么每个作用域都跑一遍
逐文字节点对比度扫描（脚本思路见本文上半），只看截图会漏掉表格这类不在首屏的块。
