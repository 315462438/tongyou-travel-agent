# 证书已续期但 nginx 仍提供过期证书

现象：iOS 显示网络不可用，公网 curl 严格 TLS 校验报 certificate has expired；后端本机健康接口正常，服务和资源正常。

原因：Certbot webroot 已成功更新磁盘证书（有效至 2026-12-25），但缺少续期成功后的 deploy hook，nginx 内存仍提供 2026-10-26 05:24:21 UTC（北京时间 13:24:21）过期的旧证书。仅看 certbot certificates 无法发现实际服务证书已过期。

处理：nginx -t 后 systemctl reload nginx，恢复 HTTPS；部署 backend/deploy/certbot-reload-nginx.sh 至 /etc/letsencrypt/renewal-hooks/deploy/20-reload-nginx，root:root、755，由现有 certbot.timer 在续期成功后触发。

核验必须同时检查磁盘证书和实际 TLS 握手证书，并使用不加 -k 的 HTTPS 请求。reload 命令返回时新 worker 可能尚未完成切换，本次紧随 reload 的首次请求仍读到旧证书，后续复核已切换至新证书。无需重启后端或重装客户端。
