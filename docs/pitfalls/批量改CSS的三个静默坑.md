# 批量改 CSS 的三个静默坑：前缀误伤 / % 格式化 / 块解析破坏语法

- 日期：2026-10-19
- 场景：把 Web 端全站改成 iOS 玻璃拟态，用 Python 脚本批量替换 `index.css`（近万行）

改造过程中脚本改了 4 轮才干净，三个坑都**不报错**，只有肉眼核对才能发现。

## 坑一：按选择器前缀批量替换，误伤了子元素

**现象**：第一版脚本用"选择器包含 `.trips-overlay`"筛选浮层，结果 54 条规则被玻璃化——包括
`.trips-overlay .trip-table-row`（表格行）、`.trips-overlay .trip-edit-grid input`（输入框）、
`.trips-overlay .trip-map-switch-track::after`（开关滑块）。表格行半透明后叠在玻璃卡上，
文字对比度掉到不可读；输入框自身再叠一层 `backdrop-filter`，模糊叠模糊。

**原因**：`.trips-overlay` 是**全屏覆盖层的根类**，几乎每条协同行程的规则都以它为前缀。
`in` / `startswith` 这种包含判断，在全站单一样式体系里等于「匹配一切」。

**解决**：匹配必须**精确**——`split(',')` 后每个选择器 `strip()` 完**完全等于**目标类，
且只处理「容器级」选择器：

```python
parts = [x.strip() for x in sel.split(',')]
if not all(p in TARGETS for p in parts):  # 完全相等，不是 in 字符串
    return unchanged
```

**一般化：批量改样式时，"容器"与"容器里的元素"必须分开筛；前缀匹配在单一前缀体系里等于全匹配。**

## 坑二：`%` 格式化字符串里混入 `180%`

**现象**：脚本抛 `ValueError: unsupported format character ')'`，因为拼接的 CSS 片段里有
`saturate(180%)`，而代码用 `'... saturate(180%) ...' % (radius,)`——`%` 后跟 `)` 被当成格式符。

**解决**：拼 CSS 用 f-string 或纯字符串拼接，**永远不要用 `%` 格式化含百分号的 CSS**。
这个错误会中断脚本但**不会**写坏文件（写盘在最后一步），所以重跑即可；但如果写法改成边循环边写，
就会留下半个文件。

## 坑三：正则块解析吃掉 `}`，注释被拼接、留下孤儿 `from/to`

**现象**：用 `re.finditer(r'([^{}]*)\{', css)` 提取规则块后，文件里出现：
- 两条段落注释被拼成一行：`/* ---------- 登录：登机牌（...取代/* ---------- 登录：登机牌...`
- `@keyframes` 被删掉但 `from {...} to {...}` 留了下来

浏览器会跳过坏注释之后的规则，**不报错但整段样式失效**；`from/to` 孤儿也会让后续声明错乱。

**原因**：`([^{}]*)` 会跨越上一个 `}`，导致下一块的选择器把前一块的收尾 `}` 和注释一起吞进去。
按「块」做增删的脚本必须自己配平大括号，而不是依赖这个正则当作块解析器。

**解决**：改完 CSS 后**无条件核对平衡数**（一条命令就能发现）：

```bash
python3 -c "s=open('index.css').read(); print(s.count('{'), s.count('}')); print(s.count('/*'), s.count('*/'))"
```

两对数不相等就是坏了。本项目的 `visual-regressions.test.mjs` 也会因为断言匹配不到而变红——
**但只在被断言覆盖到的选择器上**，`from/to` 这类孤儿它查不出来。

## 附：删死代码前先确认引用

旧登机牌样式（`.auth-sky` / `.pass-*` / `.stub-*`）整段删除时，必须先 `grep` 新登录页真正用到的类：
`.auth-wordmark` / `.auth-tagline` / `.auth-beian` / `.button-spinner` 还在用（品牌字、备案页脚、
loading 圈），一并删掉会让登录页丢字。

## 评审补充：测试通过不代表布局正确

- 批量替换把桌面的日期浮层与行程编辑抽屉规则替换成手机规则，且丢掉背景/宽度下限。外层 overflow 检查仍通过，内部表单却被裁切。测试必须检查控件边界与触发点位置。
- 新登录页引用旧 favicon 后暴露 XML 注释问题：SVG 注释中出现双连字符（CSS 变量名）属于非法 XML，文件存在、HTTP 200 仍会破图；用 naturalWidth 验收。
- 旧白色 auth-wordmark/auth-tagline 规则位于新样式之后，覆盖了浅色背景对应的深色文字。应删除过期规则，避免反复追加 override。
- 减少透明度只覆盖工具类，无法影响独立组件；用户偏好统一优先于组件样式。前缀声明放前、标准 backdrop-filter 放后，避免生产压缩只留下 Chrome 不识别的前缀声明。构建产物和浏览器计算样式都要检查。
- Portal 脱离原父层后不继承 --trip-*，需显式提供局部语义变量。锚点 ref 在布局 effect 中读取，避免首次渲染时获取空节点；媒体模拟与 React 布局完成用条件等待。
- 移动底栏 z-index 为 56，行程层为 50；编辑抽屉虽然在视口内，仍可能被导航挡住。打开抽屉时提升行程层，测试通过 elementFromPoint 确认操作按钮能被点到，而不只检查 bounds。临时 toast 先关闭再验证固定层遮挡。
