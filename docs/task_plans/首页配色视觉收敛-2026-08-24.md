# 首页配色视觉收敛（2026-08-24）

## 背景

「行记」设计系统已把散落颜色归并到 token，但首页实机截图仍有三个问题：

1. 暖黄中性色占比过高，侧栏、正文、描边一起发灰发脏；
2. 首页输入框、焦点环、阴影仍残留旧蓝紫色，与松绿/朱砂品牌色冲突；
3. 接力站横幅使用偏褐黑底并混入紫色光晕，成为页面中过重且孤立的色块。

另外，最近一次标题调整在 `.hero-eyebrow` 中留下了后置的 `color: transparent`，
覆盖了新文字色，存在品牌短句消失的回归风险。

## 目标

- 保留已确定的「实心墨主标题」方向；
- 将中性色从黄褐纸色校正为克制暖灰，减少脏感；
- 首页交互统一使用松绿，朱砂只留作品牌印记与小面积强调；
- 将接力站横幅改为深松绿/炭墨体系，移除紫色光晕；
- 桌面和移动端均不引入布局变化或横向溢出。

## 方案与涉及模块

- `frontend/src/index.css`
  - 校正 `--x-n*` 与松绿阶梯；
  - 修正 eyebrow 透明色覆盖；
  - 收敛首页输入框、焦点、阴影、顶栏、侧栏和接力站横幅颜色；
  - 实心标题停止运行无意义的渐变动画。
- `frontend/tests/visual-regressions.test.mjs`
  - 将首页视觉契约从旧蓝紫渐变改为实心墨 + 松绿焦点；
  - 增加 eyebrow 不透明和接力站无紫色光晕的回归断言。
- `docs/test_cases/首页配色视觉收敛-验收用例.md`
  - 记录自动化与人工视觉验收项。

## 验收标准

1. 首页主标题为实心墨色，品牌短句可见；
2. 输入区默认/聚焦态均无蓝紫描边与蓝紫阴影；
3. 接力站横幅为深松绿/炭墨，不出现紫色光晕；
4. 顶栏、侧栏、页面底色属于同一暖灰中性色系，层级仍清楚；
5. `npm test`、`npm run lint`、`npm run build` 全部通过；
6. 本地桌面页面完成一次截图核对，无新增溢出和文字消失。

## 执行结果

- 已完成暖灰中性色、松绿交互色和深松绿接力横幅的收敛；
- 已修复 `.hero-eyebrow` 被残留 `color: transparent` 吞掉的问题；
- 关键文字对比度静态核对：正文 `15.20:1`、次级文字 `4.89:1`、主按钮 `6.03:1`、
  眉题 `5.53:1`、接力横幅正文 `8.97:1`；
- `npm test`：85/85 通过；`npm run lint`：通过（4 条既有 warning）；`npm run build`：通过；
- 尝试连接本地页面做浏览器截图时，当前环境没有可用的浏览器实例，因此本次未完成新的渲染截图；
  已保留该项为人工复核项，没有把静态检查冒充视觉实拍。

## 第二轮调整：真正更换主色（2026-08-24）

首轮上线截图证明，只校正明度并把蓝紫交互色换成松绿，仍然保留了“松绿 + 暖纸 + 朱砂”的
原始色彩印象，用户感知上仍是“这个颜色”。第二轮不再微调色阶，而是直接更换主色体系：

- 中性色：暖黄纸色 → 冷白与蓝灰；
- 主行动色：松绿 → 海岛蓝；
- 强调色：暗朱砂 → 小面积珊瑚橙；
- 接力横幅：绿褐炭墨 → 深海蓝；
- 保留墨色标题与白色内容卡，不改变布局和信息层级。

兼容策略：现有 CSS 广泛引用 `--x-pine-*`，本轮新增 `--x-ocean-*` 作为真正的品牌色源，
旧 `--x-pine-*` 暂时作为兼容别名指向海岛蓝，避免一次大范围重命名引入布局之外的回归。

### 第二轮执行结果

- 海岛蓝主色 `#176F89`、冷白蓝灰中性色和珊瑚强调色已落地；
- 关键对比度：主按钮 `5.72:1`、眉题 `4.73:1`、正文 `15.03:1`、次级文字 `5.12:1`、
  接力横幅正文 `7.86:1`；
- `npm test` 85/85 通过，lint 通过（4 条既有 warning），生产构建通过；
- 已部署至线上，页面引用新样式 `index-CwO1p6pf.css`，服务健康检查通过。

## 第三轮调整：标题蓝天白云渐变（2026-08-24）

第二轮上线截图中，页面交互色已变为海岛蓝，但主标题仍是纯墨色，与品牌主色脱节。
本轮只调整首屏标题区：

- 整句标题共享同一组纵向渐变，每个字都是“深海蓝 → 天空蓝 → 云白高光 → 深海蓝”，
  不按词语切换颜色；
- 使用细描边和轻投影托住云白高光，避免浅色背景上丢失笔画；
- 标题渐变保持静态，不恢复会移动的 sheen；
- 首屏氛围光移除珊瑚粉，只保留天空蓝与云白。

### 第三轮执行结果

- 标题统一渐变、细描边和云白氛围光已落地；
- `npm test` 85/85 通过，lint 通过（4 条既有 warning），生产构建通过；
- 已部署至线上，页面引用新样式 `index-CGNXMhVV.css`，服务状态 `active`。

## 第四轮调整：移除青绿倾向与标题高光（2026-08-24）

第三轮上线截图显示，`#176F89` 仍属于偏绿的青蓝，云白横向高光叠加描边后又产生了霓虹/立体字观感。
本轮改为：

- 主色从青蓝切换到皇家蓝 `#2563EB`，浅色阶使用天空蓝，不再含松绿/青绿色相；
- 新增 `--x-sky-*` 为真正品牌色源，`--x-ocean-*` 与 `--x-pine-*` 仅作兼容别名；
- 标题改为统一的深海军蓝到皇家蓝纵向渐变，删除白色横纹、描边和投影；
- 首页所有主描边、焦点环、按钮阴影和接力横幅同步改为纯蓝体系；
- 珊瑚橙只保留在品牌图标和极小面积点缀中。

### 第四轮执行结果

- 皇家蓝/天空蓝 token、纯蓝首页交互态和简化标题渐变已落地，日序 Day 2 色也不再使用绿色；
- `npm test` 85/85 通过，lint 通过（4 条既有 warning），生产构建通过；
- 已部署至线上，页面引用新样式 `index-C_WalVQK.css`，服务状态 `active`。

`17` 改为皇家蓝、`同游` 改为深海军蓝；登录页白色品牌字维持原有独立规则，品牌图标继续作为
