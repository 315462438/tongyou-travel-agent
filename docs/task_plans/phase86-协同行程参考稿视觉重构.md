# Phase 86：协同行程参考稿视觉重构

## 背景

现有协同行程已经具备时间线、每日地图、住宿/费用/助手/动态、群聊和行程操作等完整能力，
但桌面界面仍偏工程面板：顶部信息层级松散，三栏之间缺少清晰的工作区边界，
地点卡片与参考稿的旅行手册感差距较大。

本次以用户提供的 `travel-planner-final(1).html` 为视觉与布局参考，不复制其演示数据或删减
现有业务能力，只迁移其核心排版语言：双层顶部导航、胶囊标签、白色圆角卡片、柔和边框与
克制阴影。配色继续继承平台现有蓝紫视觉 token，不迁移参考稿的米色/棕橙主题。

## 目标

1. 让协同行程在桌面端形成参考稿式“顶部行程信息 / 左侧预算与天数 / 中间事件时间线 / 右侧地图”结构。
2. 将日期切换和助手功能切换统一成参考稿式胶囊导航，减少漂浮控件感。
3. 提升地点卡片的信息层次、操作按钮可发现性与长行程浏览效率。
4. 保留地图、AI 提案、检查中心、住宿、记账、动态、群聊、分享、邀请和移动端分区切换。
5. 移动端继续保持单面板切换，不因桌面视觉重构产生横向溢出或触区缩小。

## 方案

### 结构

- 顶部品牌条保留“协同行程”入口语义，改为轻量半透明说明条。
- 行程标题栏改为参考稿式主导航：返回、标题/目的地/天数、成员头像、群聊、行程操作。
- 顶部同时提供 Day 与功能胶囊；Day 显示对应事件，功能标签把左侧切换为助手/住宿/费用/动态。
- 桌面主体采用三段式：左侧约 250px 展示总预算、实际支出、进度和每天导航；中间为当前 Day
  的完整事件时间线；右侧地图固定约 390–430px。
- 中间事件使用大卡片 + 纵向时间轴，不再把紧凑地点卡片直接当成整块左栏。
- 事件时间统一显示为时间段：有 `stay_min` 时由开始时间计算结束时间；缺少停留时长时使用
  下一事件开始时间；仍无法确定则显示“待定”，不编造持续时间。
- 右侧地图在 Day 与功能视图间持续保留；功能标签只替换中间内容，左侧预算/天数与地图均不跳位。

### 视觉

- 局部 `--trip-*` token 仅作为语义别名，分别映射平台 `--tx-bg`、`--tx-surface`、
  `--tx-line`、`--tx-brand`、`--tx-ink`、`--tx-muted`，确保协同行程随平台主题统一变化。
- 地点卡、面板和地图统一 14–18px 圆角；阴影只用于悬停和当前选中层级。
- Day 使用平台蓝紫强调；地图路线仍保留每日多色，避免破坏已有路线辨识。
- 仅在 `.trips-overlay` 范围内覆盖视觉 token，避免影响主对话、同游圈等页面。

### 响应式

- `<= 1180px` 适度收窄两侧栏并隐藏非必要说明。
- `<= 900px` 和显式移动布局继续使用“行程 / 地图 / 助手”三段切换。
- 移动端顶部信息压缩，胶囊导航可横向滚动，操作按钮保持至少 40px 高。

## 涉及模块

- `frontend/src/pages/Trips.tsx`：补充结构语义类名与参考稿式导航分组。
- `frontend/src/index.css`：新增 Phase 86 协同行程局部主题、桌面和移动端覆盖。
- `frontend/tests/visual-regressions.test.mjs`：验证主题 token、三栏比例、胶囊导航、移动端降级。
- `docs/test_cases/phase86-协同行程参考稿视觉重构-验收用例.md`：人工与自动化验收说明。

## 验收标准

1. 桌面端沿用平台蓝紫配色，主内容为左预算/天数、中事件、右地图三段式，排版与参考图一致。
2. Day 与功能标签均呈胶囊导航，当前项使用平台主色明确强调。
3. 左侧地点卡正文、时间、标签、备注、操作区层次清楚，悬停不产生明显跳动。
4. 左侧预算能显示预算额、实际支出与使用比例；Day 项显示日期和事件数量并可切换。
5. 地图固定在右侧，事件卡片在中间获得主要阅读宽度；切换功能标签时中间内容替换而两侧不跳位。
6. 弹出菜单、群聊抽屉、地图 marker 和板内弹窗层叠关系不退化。
7. 显式移动端和窄屏仍一次只显示一个面板，无横向溢出。
8. `npm test`、`npm run lint`、`npm run build` 全部通过。
