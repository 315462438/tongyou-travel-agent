# 我的工具弹层被账户页遮挡

## 问题与方案
网页与 Android 共用的“我的”页面 z-index=60，高于工具 modal-mask 的 50，点击入口后实际弹层被覆盖。公告、用户管理、帮助、记忆、技能、连接均受影响。
在 journey-shell 内给顶层 modal-mask 统一高于页面/底部导航/AI/历史的层级，账户页面在工具打开时 inert，关闭后保留账户页面和展开状态。补齐连接面板 Escape 关闭。iOS 不修改。

## 验收与发布
- 浏览器使用 fixture 测试六个入口一次点击即显示且控件真实命中，不点击“完成”；关闭/ESC/Android 返回后仍停留我的，可再次打开。
- 窄屏 Android、手机 Web、桌面、深浅外观，以及普通用户不显示用户管理。
- Android instrumentation 在包内快照验证公告和用户管理，系统返回正常。
- 前端 build/test、Android 打包与签名校验通过后部署 Web、发布 0.8.2 (13) 更新；更新下载链接和清单校验。
