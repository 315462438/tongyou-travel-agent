# HTTPS 证书续期未加载修复

目标：恢复 iOS 使用的 HTTPS API，并避免证书续期后 nginx 继续提供旧证书。

诊断：2026-10-26 后端健康检查 200，nginx/后端/PostgreSQL active，资源充足。磁盘证书有效至 2026-12-25，但实际 TLS 握手证书于 2026-10-26 05:24:21 UTC 过期。Certbot 使用 webroot，未配置 deploy hook。

方案：先 nginx -t，再平滑 reload nginx；新增 Certbot deploy hook，在续期成功后先检查 nginx 配置，再 reload。不重启业务后端，不发布应用代码。

涉及：服务器 /etc/letsencrypt/renewal-hooks/deploy/ 与仓库 backend/deploy/ 运维脚本。

验收：公网严格 TLS 校验通过、health 返回 200/ok；无凭据业务接口返回 401；服务实际证书与磁盘证书一致；hook 通过成功及配置错误分支自动化测试，并在服务器执行成功。

完成：已恢复公网 HTTPS，并安装、执行续期 deploy hook；2 项自动化测试通过。线上检查和真机验证边界见对应测试用例文档。
