# 地点导航直达（Phase 100）

2026-08-20　借鉴 [travel-plan-viz](https://github.com/zexuanw958-svg/travel-plan-viz) 的
navigation deep link（该仓库其余设计——机械校验、内容契约——我们已有更成熟的版本，不采纳）

## 问题

协同行程板上每个地点都有精确坐标（Phase 62 地理编码过），但用户想真去导航时，
只能自己打开高德手动搜一遍。全仓搜 `uri.amap` / `maps.apple` / `androidamap` / `geo:`
**一处都没有**。

## 方案

在地点行的操作区加一个「导航」入口，拼 deep link 跳转到用户自己的地图 App。

**不消耗我们的高德配额**：deep link 由**用户设备**发起，落到高德 App 或高德官网 C 端，
与开发者 key 无关，URL 里也不含任何 key（与 Phase 13/18「静态图后端签名代拉、key 不进前端」
是同一条纪律的另一面）。顺带它还是现有配额的泄压阀——用户想缩放/看周边/导航的连续交互
全部转移到高德 App，不再经过 `/api/staticmap`。

### 坐标系分流（本方案唯一有技术含量的部分）

`travel_trip_stop.location` 是 `"lng,lat"`，但**混着两套坐标系**
（`models.py:336`：国内高德 GCJ-02 / 海外 WGS-84）。这不是缺陷——GCJ 的偏移算法只在
中国境内生效，境外 GCJ≈WGS，而我们全程用高德渲染，所以一直是对的。

但一旦往外发链接，分流就必须显式：

| 目标 | 境内坐标 | 境外坐标 |
| --- | --- | --- |
| 高德 URI | 直接传（本来就是 GCJ） | 直接传（境外两者相等） |
| 苹果地图 | **必须 GCJ→WGS 转**，否则偏 ~500m | 直接传 |

所以只需要实现 **GCJ→WGS 一个方向**，且只在「境内 + 苹果地图」这一格用到。
`out_of_china` 判定用经纬度包围盒（业界通行做法，边境略有误差但对导航无影响——
误判的后果是境外坐标被多转一次，而境外转换量本身≈0）。

### 落点

- **纯函数** `app/agent/nav_links.py`：`gcj_to_wgs84` / `out_of_china` / `build_nav_links`，
  可单测、不依赖任何服务
- **后端** `_stop_dict` 增加 `nav` 字段（`{amap, apple}`），前端直接用，不在前端重算坐标转换
  （转换逻辑只有一处，避免两端漂移）
- **前端** 地点行操作区加「导航」按钮：`<a target="_blank" rel="noopener">`

### 链接形态

```
高德：https://uri.amap.com/navigation?to={lng},{lat},{name}&mode=car&coordinate=gaode
苹果：https://maps.apple.com/?daddr={lat},{lng}&q={name}
```

用「导航」而非「看位置」：用户在行程板上已经看得到地图，缺的是「现在出发去这个点」。

## 验收标准

`tests/test_nav_links.py`：

1. 境内坐标 → 高德链接坐标**原样**、苹果链接坐标**已转换**（与原值有可测偏移，且量级在
   100–1000m 之间——太小说明没转，太大说明转错）
2. 境外坐标（东京/纽约）→ 两个链接坐标**都原样**
3. `out_of_china` 边界：北京/上海/乌鲁木齐=境内；东京/纽约/新加坡=境外
4. `gcj_to_wgs84` 与已知参考值一致（用高德官方文档的换算量级校验）
5. 名称中的 `&`/`#`/空格/中文正确 URL 编码，不破坏链接结构
6. 坐标缺失/格式非法（空串、`"abc"`、只有一个数）→ 返回 `None`，不抛异常
7. `_stop_dict` 输出含 `nav`；无坐标的地点 `nav` 为 `None`
8. 全量回归无新增失败

## 刻意不做

- **不加到攻略正文**：那里没有坐标（只能降级成关键词搜索，会搜歪）、无法可靠识别"哪个词是
  地点"（模型标记会漂移 / 字符串匹配假阳性）、且满屏蓝链接与 Phase 64 的可读性改造冲突。
  更根本的是——首页问答是**规划**场景，导航是**出行**场景，真要导航时用户已经导入行程板了。
- **不做 WGS→GCJ 反向转换**：没有用例。
- **不做百度地图**（BD-09 还要再转一层）、**不做微信内置浏览器的唤起兼容**
  （微信限制外部 App 唤起，落到网页版是可接受的降级）。
