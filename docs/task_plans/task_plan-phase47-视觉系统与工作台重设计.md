# Task Plan — Phase 47：视觉系统与旅行工作台重设计

## 目标

在 Phase 46 已补齐交互状态的基础上，解决登录页、对话页、管理弹窗与协同行程之间视觉语言
割裂的问题。建立统一的旅行工作台设计系统，提升首页任务入口、长攻略操作和协同行程桌面端的
信息层级，同时保持后端 API、现有业务能力和国风海报产物不变。

## 设计方向

- 视觉基底：暖白与雾灰作为大面积背景，天空蓝到靛蓝作为品牌强调，珊瑚橙用于提醒；
- 统一令牌：颜色、阴影、圆角、边框、焦点环和页面间距集中定义；
- 页面结构：主工作区优先，低频信息进入上下文抽屉或“更多操作”；
- 动效：只保留短距离渐显、状态切换与必要反馈，并继续尊重减少动态效果设置。

## 方案

### 1. 首页与对话

- 将空态胶囊升级为任务卡片，展示用途、预计耗时和能力类型；
- 调整标题、说明、输入框和快捷任务之间的层级与留白；
- 将助手消息的复制、调用链、海报、导入行程收敛成统一操作栏；
- 长攻略增加轻量目录入口，方便跳到各级标题。

### 2. 管理面板

- 记忆、技能和用户管理在桌面端改为右侧抽屉；
- 移动端改为底部 Sheet，保留遮罩和 Escape 关闭；
- 统一标题区、说明、列表行和危险操作样式。

### 3. 协同行程

- 时间线和地图保持主工作区，AI/检查/记账作为可收起的上下文栏；
- 顶部只保留返回、标题、目的地、成员与“行程操作”；
- 来源对话、分享、邀请等低频动作归入操作菜单；
- 小屏继续沿用 Phase 46 的三段切换，不受桌面折叠逻辑影响。

## 验收标准

- 首页任务卡片层级清楚，在桌面与 390px 小屏均无横向溢出；
- 助手消息操作统一，不再散落多个视觉样式不同的按钮；
- 长攻略目录可展开并跳转到对应标题；
- 记忆、技能、用户管理在桌面为右抽屉、手机为底部 Sheet；
- 桌面协同行程 AI 栏可折叠，低频操作不再挤占标题栏；
- 前端测试、lint、TypeScript、生产构建通过，后端回归保持全绿；
- `frontend/dist` 与 `backend/static` 保持一致。
