# 当前连接 iPhone 安装

用户要求在现在连接的 iOS 设备上安装，并补充是朋友的手机，通过自己的电脑安装。目标是本次 USB 连接的 `iPhone (2)`，不操作仅通过局域网可用的另一部 iPhone。

## 方案

1. 完成系统配对，读取目标设备开发者模式及已装应用版本。
2. 沿用当前仓库 iOS 1.0.22 (23)、原包名和团队，为目标设备构建 Release 并校验签名、描述文件与版本。
3. 安装时不卸载应用；查询目标设备实际安装版本并尝试启动。
4. 留存安装与验证结果；系统信任、开发者模式或手机解锁操作由用户在手机上完成。

本任务不调整功能、版本号，不部署 Web、Android 或后端。验收以签名检查、实际安装版本和启动结果为准。
