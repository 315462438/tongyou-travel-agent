目标
优化 Android 手机上首页、行程、记账、历史、同游圈与弹窗的布局，参照 iOS 的大标题、蓝紫浅背景、轻玻璃卡片、浮动底栏；保持功能与账号数据兼容。

方案与模块
1. frontend/src/nativeAndroid.css 使用 html.native-android 限定专属排版，统一字号、留白、触控尺寸、卡片、表单和底部 sheet。保留 reduced-motion/低透明度降级，长列表不逐行 blur。
2. 必要的 React 展示调整通过 isAndroidApp 分支，不改网页默认交互；原生 MainActivity 处理状态栏外观并保留系统安全区/键盘行为。
3. Android 升级为 0.2.0 (2)，沿用签名与包名，生成独立 APK 快照；不发布网站 UI，不构建 iOS。
4. 新 APK 发布到独立版本化下载目录，旧链接保留。

验收
320/390/430 宽度首页、行程长标题、账本列表/详情/空说明记账、历史和社交不横向溢出；导航/表单按钮可点；输入键盘展开不遮挡保存；底栏不盖最后内容。
浏览器 Android 桥接/返回/分享回归与普通网页移动布局回归通过；TS、单测、lint、Android 单测/lint/编译、模拟器原生测试与同签名覆盖安装通过。
本地和 APK 内快照截图人工检查；线上下载 hash 与新版本清单一致；鸿蒙 7 真机兼容性仍待用户设备验证。

用户追加（开发中）：网页切移动模式后恢复常驻布局切换入口；修复桌面窗口内手机预览的接力卡竖排；首页补齐深度推理与联网搜索，复用现有发送状态/协议并验证实际请求字段。
这些共用修复需发布 Web 静态资源；Android 独有样式仍用 native-android 限定，iOS 原生已有开关无需改动。

实现结果：Android 0.2.0 (2) 已构建与覆盖安装验证；独有样式、原生导航栏、首屏不自动弹键盘完成。Web 已发布追加修复（模式切换、接力卡、自选推理/搜索）；保留桌面移动预览刷新时的侧栏收起状态。详细验收见 docs/test_cases/android-ios-style-results-2026-10-19.json。
