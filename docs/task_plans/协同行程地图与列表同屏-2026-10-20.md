# 协同行程地图与列表同屏

## 目标
用户反馈协同行程仍显复杂，希望地图和行程在同一页面。以手机体验优先，三端保持同一信息结构，保留协作、编辑、邀请、账本和导入定位逻辑。

## 方案
- 默认采用上方路线地图、下方当天地点列表；桌面宽屏地图与列表左右分栏。未收到其他布局选择，按推荐的上下布局实现。
- 删除地图/行程互斥切换，压缩重复标题、统计和操作卡；日期横向选择、添加和 AI 操作保持可达。
- 地点与地图双向联动；编号按完整当天顺序，未定位地点不编造坐标、不挤占编号。切日清除选中并展示当天点位。
- 地图失败/无位置有紧凑提示，地点列表始终可用；定位刷新不覆盖用户修改。
- 兼容浅深主题、小屏、横屏与减少动态；地图署名保留。

## 涉及模块
iOS TripsView / AppRouter 与根导航；Web Trips / AndroidTripWorkspace / TripMap / 样式；浏览器与 iOS、Android 测试夹具。

## 验收
1. 手机首屏可同时看到地图区域与至少一项当天安排；不需要切换视图。
2. 点击地点定位、点击标记选中列表，切日期正确更新；无坐标、空日、地图失败均能编辑行程。
3. 编辑/群聊/成员/返回及键盘布局无回退；旧主页和账本行为不受影响。
4. 前端构建、相关单测/浏览器、iOS 编译与 UI 测试、Android 原生流程通过。
5. 完成后重新部署 Web、更新用户 iPhone，并将安卓尚未发布的 0.7.0 (10) 一并发布；沿用签名和原子更新清单。

## 完成
已实现三端地图与当天地点同屏、双向定位、完整编号、全览、切日、地图失败回退及移动布局；详情收起底栏。iOS 1.0.9 (10) 已安装，Web 已部署，Android 0.7.0 (10) 已发布且旧版检查更新/覆盖安装通过。详见对应测试用例文档。主页字号与此前确认的新首页布局保持。
