# 直答追问按钮、地点卡与好友入口（2026-11-10）

## 要解决的问题

1. 直答经常以反问结尾（「你在哪个区、想纯泡汤还是带吃饭」），手机上得打字回答。
2. 回答里推荐了店，用户要导航、要记下来，都得另外搜、另外问；聊天和行程板是断开的。
3. 同游圈隐藏后，好友关系还在，但三端都没有任何地方能看好友、加好友、处理申请。

界面原则：不加新的主入口。追问和地点卡长在回答下面；好友放进「我的」第一行。

## 方案

### 追问按钮（`meta.suggestions`）
- 直答 prompt 末尾加一句：回答写完后另起一行写 `[[追问:A|B|C]]`（2-3 个、≤12 字、用户口吻）。
  **同一次生成里带出来，不加调用、不挡终稿**（Phase 103）。
- `_split_suggestions` 终稿时把这行从正文拿走放进 meta；`_hide_suggestion_tail` 流式中不让它闪现。
- 模型没写/写歪 = 没有按钮，正文不受影响（不把正确性押在格式遵循上）。被截断的回答不出按钮。
- 客户端只在**最后一条回答**且不在生成时显示；点一下等于发送这句话。

### 地点卡（`meta.places`）
- 复用直答配图那一步的地点查询（`amap.search_poi_photos` 现在同时返回地址和坐标，没图也返回）。
- 只给**回答里真的提到了**且有坐标的地点出卡：名称 / 地址 / 图 / 导航链接（`nav_links.build_nav_links`，后端算好）。
- 卡上两个动作：导航（境内高德、境外苹果/谷歌）；加入行程（选已有行程或新建，走现有 `POST /trips/{id}/stops`，带坐标免地理编码）。
- 不新增接口。

### 好友入口
- 网页/安卓：「我的」第一行「好友」，带新申请数；打开 `SocialHub` 的 `friendsOnly` 模式（隐藏接力站、侧栏、接力统计）。
- iOS：新增原生 `FriendsView`（搜索加人、接受/忽略申请、好友列表），入口同样在「我的」第一行带角标。
- 后端 `/api/social/friends*` 不改。

## 涉及模块
