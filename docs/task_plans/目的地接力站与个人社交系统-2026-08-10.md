# Phase 81 · 目的地接力站与个人社交系统 MVP

日期：2026-08-10

## 目标

把首页“实境预演”替换为具有公共数据沉淀能力的“目的地接力站”，并补齐社交关系的基础设施：
个人头像、公开主页、旅行偏好资料、好友搜索/申请/处理和好友列表。

本期社交与现有多人协同严格分层：多人协同仍是熟人围绕一份私密行程编辑；接力站是登录用户围绕
目的地公开发布、验证和复用旅行经验，好友系统提供跨行程的长期关系。

## 功能范围

### 目的地接力站

- 首页原实境入口替换为“天堂寨接力站”社交入口；
- 接力内容分为“准备去 / 正在玩 / 刚回来”三个旅行阶段；
- 内容类型支持现场情报、路线分享和目的地提问；
- 发布时必须填写目的地与正文，现场情报默认 72 小时过期；
- 用户可对内容标记“有用 / 已验证 / 已失效”，同一用户对同一内容只保留一种反馈；
- 仅作者可删除自己的内容；内容显示作者资料、时间、状态与反馈计数；
- 第一版不开放陌生人私信和精确实时位置，降低骚扰与人身安全风险。

### 好友与个人主页

- 个人资料：显示名、头像、简介、常驻城市、旅行风格标签、主页是否公开；
- 头像复用现有安全图片上传链路，只能绑定本人上传的图片；
- 用户搜索只返回公开主页，不暴露密码、token、管理员信息或私人行程；
- 好友流程：发送申请、收到申请、接受/拒绝、好友列表、删除好友；
- 防止给自己申请、重复申请和反向重复关系；
- 个人主页显示接力次数、内容被验证次数、好友数与最近公开接力。

## 数据模型

- `travel_user` 新增公开资料字段：`display_name`、`avatar_upload_id`、`bio`、
  `home_city`、`travel_styles_json`、`profile_public`；
- `travel_friendship`：requester/addressee、pending/accepted/rejected、时间；
- `travel_relay_post`：作者、目的地、阶段、类型、正文、过期时间；
- `travel_relay_reaction`：post + user 唯一，reaction 为 useful/verified/outdated。

迁移继续走启动时幂等 `Base.metadata.create_all + ALTER TABLE ... IF NOT EXISTS`，不引入第二套数据库。

## API

- `GET/PATCH /api/social/me`
- `GET /api/social/users?q=`、`GET /api/social/users/{user_id}`
- `GET /api/social/friends`
- `POST /api/social/friends/request/{user_id}`
- `POST /api/social/friends/{friendship_id}/respond`
- `DELETE /api/social/friends/{friendship_id}`
- `GET /api/social/station?destination=`
- `POST /api/social/posts`
- `POST /api/social/posts/{post_id}/react`
- `DELETE /api/social/posts/{post_id}`

全部 API 必须登录；头像文件读取沿用现有不可枚举 UUID 公共图片路由。

## 前端方案

- 新增懒加载全屏 `SocialHub`，包含“接力站 / 好友 / 我的主页”三页；
- 桌面侧栏增加“同游圈”，移动端底部导航用“同游圈”替换低频记忆入口；
- 用户卡点击进入个人主页，头像同步显示；
- 首页社交入口展示三个阶段与“真实旅行者接力”价值，不再使用模糊景区图；
- 接力站使用目的地切换、阶段筛选、结构化发布器和反馈按钮；
- 好友页分为待处理申请、我的好友和用户搜索；
- 主页支持头像上传、资料编辑、标签多选与隐私开关；
- 手机端为全屏单列，桌面端为左导航 + 主内容 + 轻量信息栏。

## 验收标准

1. 注册存量用户无需补资料即可正常使用，迁移幂等；
2. 头像文件类型/大小继续受现有上传安全策略限制，不能绑定他人的上传；
3. 好友申请状态机、本人/重复关系校验和权限完整；
4. 接力内容发布、筛选、反馈、过期标记和作者删除完整；
5. 私人行程、会话、记忆不进入公开主页或用户搜索响应；
6. 桌面/移动端可用，Escape 与关闭按钮有效；
7. 后端测试、前端测试、lint 和生产构建全部通过后部署。

## 实施结果

- 已新增 `social_api.py` 与三张社交表，并通过启动迁移为存量账号补齐资料字段；
- 已将首页低实用性的“实境预演”入口替换为同游圈接力站，保留现有私密协同行程；
- 已完成目的地/阶段筛选、接力发布、72 小时情报、单选反馈和作者删除；
- 已完成好友搜索、申请、接受/拒绝、撤回/删除，以及公开/好友可见主页；
- 已完成头像上传绑定、旅行名片编辑、旅行风格、公开开关、统计与最近接力；
- 已补齐桌面和移动端入口、懒加载、关闭行为与社交界面响应式样式；
- 自动化结果：后端 781 项、前端 58 项全部通过；lint 仅保留 2 条历史 Fast Refresh 警告。
