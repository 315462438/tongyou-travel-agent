# Phase 18 — 手账海报升级为「城市旅行路线图」杂志版

## 背景 / 目标

现有手账（Phase 13）是竖排逐 Day 卡片 + 每天一张静态地图，信息堆叠、观感一般。
用户参考小红书「杭州旅行路线图」希望改成**杂志三栏路线图**风格，并把
**酒店 / 美食 / 景点推荐都标上去**。

## 参考版式（brief 已锁定视觉方向 → 严格遵循，不用默认三件套）

```
┌──────────────────────────────────────────────┐
│  杭州 · 旅行路线图        （毛笔标题 + 印章）    │
│  西湖烟雨·茶香宋韵·运河繁华   （主题短语）        │
├──────────┬────────────────────┬───────────────┤
│ 路线一    │                    │ 🍜 美食推荐    │
│ 西湖经典线│    中心路线地图      │  [图] 西湖醋鱼 │
│ ①②③④…    │  按天编号点位+连线   │  酸甜鲜嫩…     │
│ 约X公里   │                    │ 🏨 酒店推荐    │
│ 建议半日游│                    │  [图] 名/地段  │
│ 路线二…   │                    │ 🎁 当地特产    │
│          │                    │ 💡 旅行贴士    │
├──────────┴────────────────────┴───────────────┤
│  三条路线一览（Day 汇总）                        │
│  ✿ 旅行智能体 · 手账 ✿                          │
└──────────────────────────────────────────────┘
```

- **能做**：杂志版式 + 信息设计 + 水墨国风配色/毛笔标题 + 高德静态地图（按天编号 marker + 连线）
  + 美食/酒店/特产/贴士卡片（带实景图）。
- **不能做**：参考图那种纯手绘水彩地图是画师作品，无法程序化生成 → 用高德静态地图近似，
  外套宣纸/胶带/毛笔框营造国风。（已在文档说明预期）

## 设计 token（国风水墨，非默认三件套）

- палitra：宣纸米白 `#f6f1e4` / 竹青绿 `#3f6b52`(标题) / 墨黑 `#2d2a26` / 朱印红 `#b23a২f` /
  淡青边 `#c9d8cd` / 卡片乳白 `#fbf8f1`
- 字体：标题楷体/华文行楷（毛笔感，克制使用）；正文思源黑/系统；数字圆点用衬线
- 签名元素：毛笔城市大标题 + 朱红方印 + 每条路线的圆形序号点

## 涉及模块

### 后端
- `app/schemas/poster_schema.py`：新增 `PosterHotel` / `PosterFood` / `PosterSpecialty` /
  `PosterDayMeta`；`PosterData` 加 `theme`、`day_meta`、`hotels`、`foods`、`specialties`、`tips`。
- `app/agent/poster.py`：
  - `EXTRACT_SYSTEM` 扩写：抽路线主题短语、每天路线名、酒店/美食/特产/贴士。
  - 酒店、美食并发补高德实景图（`search_poi`，回退会话来源图 / emoji）。
  - `_build_poster_payload`：每天带 `title`/`subtitle`/`distance`（haversine 估算「约N公里」）
    /`duration`（按点数「建议半日/整日游」）；顶层带 hotels/foods/specialties/tips。
- `app/api/staticmap_api.py`：放开更适合竖版的尺寸（如 `600*600`）。

### 前端（`Home.tsx` PosterView 重写 + `index.css`）
- 三栏杂志版式（左路线卡 / 中地图 / 右美食+酒店+特产+贴士），底部路线一览。
- 固定设计宽度（~860px）套 `overflow-x:auto`，窄屏可滚动，html2canvas 截全图。
- 国风配色/毛笔标题/朱印/圆序号；图片加载失败回退 emoji（沿用 StopPhoto）。

## 验收标准

1. 生成的海报为三栏路线图版式，含左路线卡、中编号地图、右美食/酒店/特产/贴士。
2. 酒店、美食带实景图（缺图回退 emoji），景点在地图按天编号+连线。
3. 每条路线显示路线名 + 约N公里 + 建议时长。
4. `poster.py` 抽取单测（含 hotels/foods/specialties/tips）通过；前端 tsc 通过。
5. 线上真实攻略生成一次，观感接近参考图。
