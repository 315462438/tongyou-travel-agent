# 双主题切换与水墨主题（2026-08-24）

## 目标

在现有现代皇家蓝主题之外，新增可由用户主动切换的“水墨山行”主题。主题选择跨刷新保留，
且同时覆盖首屏氛围、标题、侧栏、卡片、主按钮与深色横幅，而不是只替换背景图。

## 设计方案

### 现代主题

维持当前皇家蓝/天空蓝、冷白蓝灰和少量珊瑚点缀。

### 水墨山行主题

- 背景：用户提供的水墨山水图，仅在空状态首屏作为低对比度氛围背景；
- 中性色：宣纸白、淡墨灰、浓墨黑；
- 强调色：朱砂印色；
- 标题：楷体/宋体回退链与实心墨色；
- 主按钮：浓墨渐变、低圆角、朱砂 focus；
- 卡片：宣纸半透明底、墨色细边与柔和纸面阴影；
- 实景图片：适度降饱和，与水墨环境融合但保留识别度。

## 交互方案

- 顶栏视图切换旁新增主题按钮；
- `现代主题 ⇄ 水墨主题` 单按钮切换，使用 `aria-pressed` 暴露当前状态；
- 选择写入 `localStorage.travel_theme_mode`；
- 非法或缺失存储值回退 `modern`；
- 移动端隐藏按钮文字、保留图标和可访问名称。

## 涉及模块

- `frontend/public/ink-landscape.webp`：用户提供的水墨主题背景；
- `frontend/src/interaction.ts`：主题类型与初始化纯函数；
- `frontend/src/pages/Home.tsx`：主题状态、切换按钮和根 class；
- `frontend/src/index.css`：主题按钮与 `.theme-ink` 覆盖层；
- `frontend/tests/interaction-utils.test.mjs`：存储值回退测试；
- `frontend/tests/visual-regressions.test.mjs`：主题入口、资源和关键视觉契约。

## 验收标准

1. 顶栏可切换现代/水墨主题，刷新后保持选择；
2. 水墨主题首屏能看到低对比度山水背景，文字和表单仍清楚；
3. 标题、按钮、侧栏、输入区、接力横幅和热门卡片形成同一水墨视觉；
4. 切回现代主题后不残留宣纸、朱砂或水墨图片样式；
5. 桌面与移动端均无新增横向溢出；
6. `npm test`、`npm run lint`、`npm run build` 全部通过。
