# Task Plan — Phase 42：分享链接加入（微信分享 → 注册 → 自动进协同板）

## 目标（用户原话）

在协同行程界面分享到微信，对方点链接进来，**注册后自动加入**该协同界面参与规划——
不再需要「知道用户名 + 手动邀请 + 等接受」。

## 方案

### 后端

- `travel_trip.invite_token`（32 位随机 hex，可空=未开启分享，迁移加列）；
- `POST /{id}/share`（仅 owner）：生成/返回 token（`{reset:true}` 重置旧链接失效）；
  `DELETE /{id}/share`（仅 owner）：关闭分享；
- `GET /api/trips/shared/{token}`：**免登录**预览（只回 title/destination/成员数——
  给落地提示「XX 邀请你加入…」用，不泄露行程内容）；
- `POST /api/trips/join` {token}（需登录）：凭 token 直接成为 accepted 成员
  （幂等：已是成员直接返回 trip_id）；成员数上限 20 防滥用；事件留痕
  「通过分享链接加入」。

### 前端

- 板头新增「🔗 分享」（仅 owner）：弹窗生成链接 + 一键复制微信文案
  （「我在『一起同游』规划〈哈尔滨行〉，点链接一起编辑：URL?join=token」）
  + 重置链接 / 关闭分享；
- **加入流**：App 载入时解析 `?join=token` → 存 localStorage（关键：撑过注册/登录
  跳转）→ 登录态就绪后 `POST /join` → 成功直接打开该协同板并清理 URL 参数；
  未登录用户先看到注册页（token 已暂存，注册完自动续接）。

### 已知边界

- 微信内置浏览器打开 IP 链接会有「非官方网页」提示——**域名 + 备案 + HTTPS 上线后
  体验才顺**（Phase 域名迁移时一并解决）；
- 链接即凭证：拿到链接的人都能加入——owner 可随时重置/关闭；成员上限 20。

## 验收

- share 仅 owner 可开/重置/关；旧 token 重置后失效（自动化）；
- join：有效 token 成为成员且幂等、无效 404、上限拦截（自动化）；
- 免登录预览只含 title/destination/人数（自动化）；
- 线上：A 复制链接发微信 → B 无账号点开 → 注册 → 自动落在同一块板上。
