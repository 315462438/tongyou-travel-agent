| 批次 | 内容 | 风险 | 本次做 |

| **② 中性色收敛** | 74 种中性 + 361 种冷灰 → 纸/墨阶梯 | 低（感知位移可算） | ✅ |

| ⑧ 渐变与插画 | 手工逐个 | 高 | 手工，最后 |

## 安全网：感知位移闸门

批量替换的危险不是"改错颜色"，是**悄悄改得太多**。所以映射脚本必须：

1. 每个 `旧色 → token` 计算 **CIEDE2000 ΔE**；
2. **ΔE > 12 的一律不自动替换**，落进人工复核清单；
3. 输出完整映射表存档，改完能逐条回看"哪个色被换成了什么、位移多少"。

⚠️ **不动的**：`.rmap-*` 海报（它本来就是调色板的来源，改了等于自我循环）、
地图 marker 色（要与高德静态图 URL 里的颜色参数保持一致）、
`Aurora`/`Iridescence`/`SideRays` 等特效组件的渐变。

## 验收

1. `npm run build` 通过；
2. 去重颜色种类从 779 降到 ≤200（余下的是渐变与插画）；
3. 映射表里没有 ΔE > 12 的自动替换；
4. 登录页（无需鉴权）桌面 + 移动双尺寸截图人工对照；
5. `tests/interaction-utils.test.mjs` 仍全绿。

# 执行结果（2026-08-24）

## 批次①–④ 色彩

| 指标 | 改造前 | 改造后 |
| --- | --- | --- |
| hex 出现 | 1558 次 / 779 种 | **161 次 / 114 种** |
| `var(--x-*)` 引用 | 91 | **1451** |

闸门从 ΔE 改成 **ΔL\* ≤ 6**——冷灰换暖墨 ΔE 天然 ~20，用 ΔE 会把改造意图本身卡死；
真正会出事的是明度变了。为此中性与三个角色色都做了按 L\* 均布的阶梯。

三个盲区见 `docs/pitfalls/按明度批量换色的三个盲区.md`。

## 批次⑤ 字阶

37 种 → **17 种**（余下零散值都在受保护的海报区），**11px 以下归零**（原 178 处，最小 8px）。
位移 ≥4px 的只有 4 处，都是本该收敛的大标题。

⚠️ `.immersive-*` 一开始被我列进保护区，但它是**真实 UI 不是海报**——7.5px 一样读不了，
已放开并上提（27 处）。保护区的判据是「这块内容是不是按固定尺寸整体呈现的产物」，
不是「它是不是特殊视觉」。

## 批次⑥ 圆角

29 种 → **4 级**（6/10/16/999），471 处替换；`50%` 与 `999px` 语义相同，一并归 pill。

## 批次⑦ 底栏图标 + 品牌

- `✦ 🗺 ☰ ⌁` → 线性 SVG（24 网格 / 1.7 描边 / currentColor）
- 底栏改墨底圆角块（chrome 用墨、内容用纸），标签 10px → 11px
- `.brand-mark`、favicon、`theme-color`、wordmark 全部换朱印色。
  **路线箭头图形不动**——那是 Phase 66 立的识别，换的只是颜色。favicon `?v=2 → ?v=3` 顶缓存。

## 验证

- `npm run build` 通过
- 测试 **84 passed**（视觉回归 38 + 交互 46）
- 渲染态实测（dev server + playwright，桌面 1200 / 移动 390 两个尺寸）：
  无横向溢出、无文字被裁、无 11px 以下字号
- **新增三条防漂移闸门**进视觉回归：字号下限、硬编码色上限（≤20）、底栏禁 emoji。
  光有 token 不够——Phase 66 的 `--tx-*` 就是没人强制用才漂成 780 种的。

## 仍未验证的

**主应用界面（对话流/行程板/同游圈）没能亲眼验证**——本地跑不起完整鉴权链路，
对比度与溢出检测只覆盖到登录页。依赖的是「保明度」这条规则的数学保证，不是实际观察。
