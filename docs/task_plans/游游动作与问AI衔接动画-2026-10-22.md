# 游游动作与「问 AI」衔接动画（2026-10-22）

## 目标

用户反馈：游游「就是一个贴图，不动的」；点「问 AI」没有衔接，面板直接盖上来。

1. 游游要有持续的生命感和随状态变化的动作。
2. 点游游进入 AI 时，要看得出「是游游带你进去的」。

## 方案

### 动作（网页 / 安卓共用 CSS，iOS 原生同构）

| 层 | 内容 |
| --- | --- |
| 常驻 | 呼吸（整体 3.4s 轻微伸缩）、眨眼（5.2s 一次）、尾巴摆、右耳偶尔抖 |
| 状态 | 生成中：低头看地图、眼睛左右扫、地图抖；等确认：歪头晃 + 头顶 `?`；停下：眯眼 + 飘 `z`；出错：耷拉头、耳朵下垂 + `!` |
| 待机小动作 | 只在空闲/完成时，每 6–12 秒随机一个（张望 / 挥手冒心 / 举地图看 / 伸懒腰 / 蹦两下），不连续重复 |
| 交互 | 拖动时朝拖动方向探身；鼠标悬停抬头看你；收起 AI 回到角落时从上方落下 |

网页实现要点：**全部用独立的 `scale`/`rotate`/`translate` 属性**叠在原姿势的 `transform` 上，原有静态造型一行不动。
待机调度在 `TravelPet` 的 `usePetAct`，纯函数 `nextPetAct`/`petActDelay`/`petActAllowed` 在 `travelPet.ts`；
页面不在前台时不播。iOS 用 `PetMotion.at(time, phase)` 纯函数算每帧，`PetLiveArt` 用
`TimelineView(.animation(minimumInterval: 1/30, paused:))` 驱动；待机动作按 9 秒窗口确定性排程。

### 问 AI 衔接

- **网页**：点击时克隆按钮里的游游，在 AI 面板上方沿弧线（先蹲后跳、空中转身）飞到标题栏小游游的位置并缩到它的大小，
  落地后标题栏小游游回弹；AI 面板同时从游游的位置**圆形展开**（`clip-path`）。安卓 WebView 用纯合成层的
  缩放+淡入代替 `clip-path`（上一轮刚处理过安卓流畅度，不冒险）。
- **iOS**：根视图顶层 `PetFlightOverlay` 做同样的弧线飞行（`Animatable` 修饰符，避免 SwiftUI 直线插值），
  `AssistantView` 加 `PetRevealShape` 遮罩从游游位置圆形展开，标题栏 `PetStatusBadge` 落地 squash 回弹。
- 游游按钮不再叠全局的按压波纹（按钮在点击当帧就隐藏了，波纹会在空处留下一块灰色圆角矩形）。

### 降级

「减少动态效果」开关或系统减少动态效果：网页所有 `.yp-art` 动画关闭、不飞行不展开；iOS `TimelineView` 暂停、
不飞行、面板无动画。iOS App 不在前台时也暂停。

## 追加：气泡互动（进度播报 + 指引）

用户追问：「应该有点互动，比如生成一个气泡通知进度或者指引用户」。动作只是「活着」，没有告诉用户任何事。

- **进度播报**：AI 生成时用户收起面板去看别的，游游头顶气泡实时显示**当前这一步**（取本轮最新一条进度消息：
  首行、去开头表情/符号、网址只留域名、超 22 字截断；开始写正文后显示「正在写回复…」），前面一个跳动小圆点。
  AI 标题栏的小游游同样显示这一步。点气泡回到 AI（带飞行衔接）。
- **结果提醒**：需要确认时「有件事需要你确认，点我去看看」，出错时「这次没能完成，点我看看」，
  完成后「回复准备好啦，点我看看」（留 8 秒，可 ✕）。
- **新手指引**：空闲 6 秒后说一句还没说过的指引——①点我直接问 AI ②长按能检查行程 ③可以拖到另一边。
  **每条只说一次**（记在当前设备的用户偏好 `tipsSeen` 里），**一次会话最多一句**，9 秒自动收起、可 ✕；
  点①直接打开 AI，点②打开旅行工具。不做重复催促（实用性优先）。
- 优先级：确认/出错/进度 > 完成提醒 > 指引。气泡是信息不是动效，「减少动态效果」下照常显示、只是不做动画。

纯函数：网页 `petProgressText`/`nextPetTip`/`petBubble`（`travelPet.ts`），iOS `TravelPetLogic.progressText`/
`nextTip`/`bubble`（`Core/TravelPet.swift`），两端同一套规则与文案。iOS `PetPreferences` 改为逐键容错解码
（新增字段不会让老用户的设置被重置）。

## 追加：气泡改对话气泡 + 离页继续跟进 + 点开直达对话（iOS 1.0.18）

用户反馈（真机截图）：①气泡是个胶囊，不像在说话；②查询完成后气泡停在「正在联网搜索…」不变，也没有完成提醒；③点进去要再从「历史」里找对话。

- **形状**：`PetBubbleShape` 圆角主体 + 底部小尾巴指向游游头顶（随停靠侧换边）；完成/出错带图标，字号 caption→footnote。
- **离页继续跟进**：原来游游的状态只来自 `ChatView` 的轮询，对话页一消失（返回、关历史）就 `stopPolling`，游游永远停在最后一条进度。现在 `ChatView.onDisappear` 时本轮若仍在跑，`AppRouter.followPet` 用 `ChatStore.refresh()` 每 2s 接着拉，完成时照常触发完成提醒 + 成功触感；对话页回来上报即停掉后台跟进。
- **不被旧对话覆盖**：`TravelPetLogic.accepts` —— 另一个对话还在跑时，打开一条已结束的旧对话不改游游状态。
- **直达对话**：路由记 `petChat`（id+标题）；点气泡（进度/确认/出错/完成）或生成中点游游 → `openPetChat()` 把该对话推到 AI 面板最上层（已在最上层则不重复推）。
- **完成提醒**：带对话名「「延吉烤海鲜」写好啦，点我看看」，不再 8 秒自动消失，直到点开、点 ✕ 或开始下一轮。

## 追加：聊天气泡 + 完成庆祝 + 攻略贴边（iOS 1.0.19）

- 气泡改为实心底（`secondarySystemGroupedBackground`）+ iMessage 式弯尾巴（11pt，尾尖落在游游头顶外侧）。
- 完成时游游跳两下带左右转身（`PetFeedbackArt(celebrate:)`），头顶冒出 🎉✨💙👏🌟 飘散（`PetEmojiBurst`）；安静模式 / 减少动态效果不出现。
- 攻略贴边：配图 `scaledToFill` 把理想宽度报得比屏幕还宽，整列被撑开、文字贴边、表格两侧被切；改为 `Color.clear` 定框 + overlay 图片。对话页左右边距 16→20。
- 配图被模型包在括号里留下孤立的「(」「)」：`InlineText.imagesOnOwnLines` 去掉包图括号并让图独占一行。

## 追加：网页 / 安卓对齐（网页部署 + 安卓 0.10.3）

- **配图括号从源头修**：模型把占位符写成「（[[img:广州]]）」，`_sub_placeholders_table_safe` 换成独占一行的图片后括号孤零零留在上下行。后端 `_IMG_IN_PARENS` 先剥括号；老攻略由网页 `prepareMarkdown`、iOS `InlineText.imagesOnOwnLines` 渲染时兜底。
- **网页后台跟进**：Home 只轮询当前对话，切到新对话 / 别的对话后上一轮的进度就不再更新。`petWatch` 记住切走时仍在跑的对话，每 2.5s 拉一次；当前对话没在跑时游游显示它，完成时照常出完成提醒；点气泡（`onAsk(from, toTask=true)`）`selectConv` 回到那个对话。
- **网页气泡 / 庆祝**：气泡 `::after` 尾巴随停靠侧换边；完成提醒带对话名（`petDoneText`）、带 ✓、不再 8 秒自动消失；完成时 `yp-hop` 跳两下 + `.pet-cheer` 五个表情飘散（安静模式 / 减少动态效果 / 矮屏不出现）。
- **手机网页留白**：`.view-mobile .thread-inner` 左右 13→18px，窄屏 12→16px。
