# AI 页面深色文字对比度修复

目标：修复 Web 夜间模式下标题、输入标签、输入内容和辅助提示不可读，保持字号、布局及交互不变。

方案：AI 工作区使用随外观切换的语义文字色；移除标题遗留的透明文字填充与渐变；输入卡、提示、上传及规划开关采用配套背景与文字色。范围仅共享前端 AI 工作区，不修改 iOS。

验收：桌面、移动 Web、Android WebView 外观的浅色/深色下，普通文字实际合成对比度至少 4.5:1，标题至少 3:1；占位符与输入内容均检查；切换系统外观不丢草稿、不改变布局；现有旅程交互测试和前端构建通过。发布 Web 并提交源码；Android 安装包版本保持不变。
