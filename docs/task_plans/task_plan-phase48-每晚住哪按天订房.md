# Task Plan — Phase 48：「每晚住哪」按天订房（多城行程酒店提效）

## 背景（用户反馈）

多城市行程（如川藏线途经成都/康定/雅江/巴塘/八宿）订酒店麻烦：酒店面板只默认搜目的地，
每个过夜城市要手动打城市名去搜、或跳携程。「每晚住哪」只干巴巴显示 N 行「未定」，
没把每天该住的城市对应起来。

（注：行程按天拆分本身没问题——Day2-7 有正常内容，只有订房流程需要提效。）

## 方案：每天自动带出城市 + 一键订该城

### 后端

- `amap.regeo(location)`：逆地理编码 "lng,lat" → 城市名（直辖市 city=[] 时回退 district/
  province）。失败返回 ""。
- `GET /api/trips/{id}/day-cities`：每天取「最后一个有坐标的地点」→ 逆地理编码出过夜城市
  （Semaphore 限并发）；无坐标的天回退 trip.destination。返回 `{cities: {day: 城市}}`。

### 前端（住宿 tab）

- 拉 day-cities；「每晚住哪」每行：
  - 该天已有住宿点（note 含🏨）→ 显示酒店名；
  - 否则 → `D{n} · {城市} · [查酒店]`，点「查酒店」→ 设 hotelCity=该城 + selectedDay=该天。
- `HotelPanel` 改为**受控 city**（父传 city + onCityChange），city 变化即自动搜；
  onAdd 仍加到 selectedDay → 酒店挂到点击的那天。
- 多城市订房：从「逐个手搜/跳携程」变成「每天点一下，城市自动带出、加到对应天」。

## 验收

- `regeo` 解析高德 regeo（含直辖市回退）（fake httpx 自动化）；
- `day-cities` 每天取最后一个有坐标点的城市、无坐标回退目的地（自动化）；
- 线上：住宿 tab「每晚住哪」每行带城市 + 查酒店；点 D3 查酒店 → 面板搜康定 → 加入 → 挂 Day3
  且出现在该行。
