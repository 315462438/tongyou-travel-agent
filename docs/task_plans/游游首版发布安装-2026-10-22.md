# 游游首版发布与安装

用户明确指令：发布，安装。

## 发布范围

- Web：发布已验收的共享前端构建，旧哈希资源保留。
- 后端：部署停止/失败终态标记，旧客户端兼容；不迁移数据库或改依赖。
- Android：0.9.3 (17) → 0.10.0 (18)，沿用正式签名，发布版本化 APK 并原子更新 latest 清单。
- iOS：已连接手机上的 1.0.14 (15) → 1.0.15 (16)，沿用团队、包名与个人签名，覆盖安装并启动。

## 顺序与验收

1. 核对线上版本、健康和原文件指纹；核对连接设备，保留回退文件。
2. 递增移动版本，构建 Android 正式签名 / iOS Release；复用上一轮逻辑、浏览器、模拟器验收结果。
3. Android 单测、lint、原生 WebView 测试与同签名覆盖安装通过；校验签名、快照、测试资产不进入正式 APK。
4. 只同步本次后端模块与前端产物，重启一次后端；健康、文件指纹、公开静态资源及兼容接口核验通过。
5. iOS 验证签名，覆盖安装到目标 iPhone，查询实际版本并启动；不卸载，不清理用户数据。
6. Android 上传官方目录，更新清单，HTTPS 下载、SHA256、Range 与最新版本核验通过。
7. 留存发布与安装结果；只有模拟器连接时，不把模拟器安装说成用户安卓真机安装。

初查：生产 Android 最新 0.9.3 (17)，iPhone 已装 1.0.14 (15)，后端 active / health ok。无安卓真机连接；可使用专用 TongyouQA35 模拟器完成安装验收。
