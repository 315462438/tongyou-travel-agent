# Phase 85 · 同游圈侧栏头像完整显示修复

日期：2026-08-11

## 目标

修复同游圈左下角当前用户卡片中头像被容器裁切、只能显示一部分的问题，同时保持卡片紧凑、
圆形头像比例和桌面/移动端现有布局不变。

## 方案

- 定位 `SocialHub` 当前用户卡片的头像节点及其专属 CSS；
- 将头像尺寸、缩放和 `object-fit` 约束收敛到卡片局部，不影响个人主页的大头像；
- 检查卡片自身的宽高、内边距和溢出规则，保证头像圆形完整展示；
- 增加前端视觉回归断言，覆盖头像容器尺寸、圆角与图片适配规则。

## 涉及模块

- `frontend/src/components/SocialHub.tsx`
- `frontend/src/index.css`
- `frontend/tests/visual-regressions.test.mjs`

## 验收标准

1. 左下角头像完整显示为圆形，不再被上下或左右裁掉；
2. 图片保持比例，不被拉伸；
3. 用户名称和城市仍完整可读，卡片点击区域不缩小；
4. 不影响个人主页头图、好友列表及接力卡片中的头像；
5. 前端测试、lint 和生产构建通过。

## 实施结果

- 左下角当前用户头像从默认 36px 规格升级为 46px 独立规格；
- 侧栏头像使用 `object-fit: contain` 与居中定位，确保非正方形或细节型图片完整显示；
- 增加半透明描边、背景和阴影，深色侧栏中头像边界更清晰；
- 只作用于 `.social-me-mini`，不影响主页、好友与接力头像；
- 前端 `58 passed`，lint 通过（仅项目已有两条 Fast Refresh warning），生产构建通过。
- 已发布至线上体验地址，服务器健康检查与最新静态资源版本均验证通过。
