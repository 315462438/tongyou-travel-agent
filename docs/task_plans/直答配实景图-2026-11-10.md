# 直答配实景图（2026-11-10）

## 背景

线上（iOS 问 AI，联网搜索开）：用户问「合肥洗浴中心」，拿到带来源的文字推荐后追问「有没有图片」，
回答是「我这边没法直接发图片给你（纯文字助手，不经手图片资源）」。

这句话不属实：攻略链路从 Phase 12 起就有高德 POI 实景图 + `/api/img` 同源代理 + `[[img:名称]]`
占位符，三端都能渲染。只是 **直答链路（`run_direct_answer`）从没接过图**——它连 `_embed_images`
都不过，模型手里没有任何图，只能如实说没有。

## 目标

直答在两种情况下带图：

1. 用户明确要图（`wants_image_refresh`：图片/照片/配图/实景图…）——取他指的地点，没指明就取上一轮
   回答推荐的那几家，每处最多 3 张。
2. 本轮开了联网搜索且有结果——回答里具体推荐的店/景点各配 1 张。

其余直答（闲聊、常识）不触发，不增加延迟。

## 方案

`run_direct_answer` 在拼 prompt 前加一步 `_direct_image_block`：

1. **挑地点**：一次 `classify`（`effort=off`，~1s），从近几轮对话 + 本轮搜索结果里挑「具体名称」
   （≤6 个）+ 城市。只许取原文出现过的名称，泛称不要。
2. **查图**：`amap.search_poi_photos`（新）并发查高德，限并发 4、整体 6s 封顶。
   - `citylimit=true` 限定城市；
   - **名称必须对得上**（包含关系，或关键词去掉城市后的头两个字出现在 POI 名里）——
     「XX洗浴中心」不能配「YY洗浴中心」的图。**配错图比不配更糟**，拿不准就不要。
   - 向后看 5 条 POI，取第一条名称对得上且有图的。
3. **进 prompt**：图名单 + 「用 `[[img:名称]]` 另起一行插入；清单外的地点如实说没找到图；
   不要自称纯文字助手」。用户要图但一张没找到时，也给一句说明（如实说没找到 + 去点评看实拍）。
4. **出稿**：流式与终稿都过 `_embed_images`（复用占位符替换、表格安全、醒目行兜底、站外图剥离）。

图片来源只有高德（已在 `/api/img` 白名单内）。**不用搜索结果网页里的图**：域名任意，
放进代理白名单等于开放代理（Phase 12/69）。

## 涉及模块

- `backend/app/tools/amap.py`：`search_poi_photos` + `_poi_name_matches`
- `backend/app/agent/orchestrator.py`：`_PhotoPlaces`、`_direct_image_block`、`run_direct_answer` 接线、
  `DIRECT_SYSTEM` 不变（说明随图名单末置到 user，保住前缀缓存，Phase 58）
- `backend/app/config.py`：`direct_images_enabled`（默认开，可关）
- 前端 / iOS / 安卓：不改（Markdown 图片本来就渲染）

## 降级

高德没配 key、分类失败、查图超时、一张没找到 → 与改造前完全一样的纯文字回答（用户要图时多一句
「没找到」）。任何异常只记 warning，不让直答失败；用户停止照常向上冒。
