# 17同游社交平台宣传视频计划

## 目标

制作一支可直接用于短视频平台的产品宣传片，突出“从一句话需求到图文攻略、协同行程和旅行接力”的完整价值链，吸引首次接触 17同游 的旅行用户。

## 成片规格

- 画幅：9:16 竖屏，1080×1920
- 时长：30–45 秒
- 编码：H.264 + AAC，30 fps
- 素材：线上真实产品页面，仅浏览现有数据，不提交新规划、不修改行程、不公开发布
- 风格：轻快、丝滑、字幕先行，适合无声浏览；使用原创合成氛围音，避免音乐版权风险

## 内容结构

1. 3 秒痛点钩子：旅行攻略不要再一个人做。
2. 首页输入：一句话补齐目的地、预算和节奏。
3. AI 攻略：展示已有图文攻略与结构化日程。
4. 协同行程：展示地图、逐日安排和群聊能力。
5. 同游圈：展示目的地接力与真实旅行情报。
6. 品牌收口：17同游 · 一起规划，一起出发。

## 涉及产物

- `marketing/promo-2026-08-24/frames/`：真实页面帧
- `marketing/promo-2026-08-24/storyboard.md`：分镜与字幕
- `marketing/promo-2026-08-24/build_video.sh`：可复现构建脚本
- `marketing/promo-2026-08-24/verify_video.sh`：自动验收脚本
- `marketing/promo-2026-08-24/17同游-社交平台宣传片-竖屏.mp4`：最终成片

## 验收标准

- 分辨率、时长、帧率和编码符合规格。
- 文字在手机端清晰，关键功能在 3 秒内进入叙事。
- 不暴露凭证，不展示恶意/无关会话，不写入或删除线上业务数据。
- 在 5 个时间点抽帧检查，无明显裁切、黑边、字幕遮挡或空白画面。
