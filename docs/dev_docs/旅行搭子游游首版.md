# 旅行搭子游游首版

定位：原 AI 入口的旅行伙伴。地图包小水獭由 CSS 和 SwiftUI Canvas 绘制，不使用外部图片，不增加静止帧定时器、定位或模型请求。

## 使用

- 轻点游游直接打开原 AI；长按打开旅行工具，左右拖动可吸边。
- “我的 → 游游 · 旅行搭子”可摸摸、检查准备、换停靠位置、减少动态或隐藏；隐藏后保留问 AI。
- 真实任务的生成、待确认、完成、停止、错误有不同文案。角色不编造完成百分比或预计耗时。
- 出发检查由用户选行程后读取详情与原 issues 接口；展示出发日期、位置、时间及路线检查项，可进入该行程处理。
- 已打开行程的成员列表发生真实新增时给一次短欢迎，首次加载和在线状态变化不触发。

## 状态与生命周期

React 纯逻辑位于 `frontend/src/travelPet.ts`，组件和样式位于 `frontend/src/components/TravelPet.*`。Home 复用原发送、轮询、停止和草稿；Trips 复用已有成员刷新。工具关闭取消请求，短动画结束后不维持循环。系统 reduced-motion 及宠物 quiet 优先关闭角色动画。

iOS 对应 `Core/TravelPet.swift`、`Design/TravelPetView.swift`，AppRouter 持有任务与设置。原生 NavigationStack 继续常驻以保留草稿；收起时主动结束键盘响应。设置写当前设备的用户命名空间，不上传服务端。

成员判断只比较同一 trip 的成功快照；第一份快照建立基线。移除不算加入，username 去重，presence 不参与判断。iOS 使用既有详情刷新/成员编辑回调，不新增长期轮询。

## 服务端兼容

停止和失败收尾新增可选 `meta.cancelled` / `meta.error` 布尔字段，正文、接口和鉴权不变；老版本可忽略。新客户端也识别旧服务的明确停止/错误文案，但无法还原旧无标记部分终稿的真实原因。

## 当前范围

已完成开发与自动化验收，未发布新三端版本。城市印章、换装、桌面组件和推送不在首版中。验收见 `docs/test_cases/旅行搭子游游首版-2026-10-22.md`。
