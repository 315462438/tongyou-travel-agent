# 开发文档：个人旅行规划浏览器智能体

## 1. 技术目标

构建一个本地可运行的旅行规划 Agent 平台。

核心能力：

```text
用户在页面输入旅行需求
后端 Agent 接收需求
Agent 直接调用 Chrome DevTools MCP
MCP 控制真实 Chrome 浏览器
Agent 自动读取网页内容
Agent 总结酒店、攻略、路线和预算
遇到登录/验证码时暂停并让用户接管
```

Chrome DevTools MCP 官方支持通过 MCP server 让 agent 控制和检查 live Chrome browser，并且可以通过 `npx -y chrome-devtools-mcp@latest` 方式接入。它也明确提示该工具会暴露浏览器内容给 agent，因此本项目必须实现动作守卫和用户接管机制。

### 说明

第一版建议使用有界面的 Chrome，不使用 headless。原因：

```text
用户需要手动登录
用户需要处理验证码
用户需要看到当前页面
用户需要在必要时接管浏览器
```

## 5.2 连接正在运行的 Chrome

如果希望 Agent 和用户共享同一个 Chrome 状态，可以使用远程调试或自动连接能力。

推荐本地自用方案：

```text
1. 用户正常打开 Chrome

```

Chrome DevTools MCP 文档说明，它可以连接运行中的 Chrome 实例，适合在手动操作和 agent-driven testing 之间共享状态。

## 10. Action Guard 设计

## 10.1 风险等级

### low：自动执行

```text
打开公开页面
读取页面标题
读取页面正文
滚动页面
截图
提取酒店价格
总结攻略内容
生成路线
```

### medium：用户确认/接管

```text
登录账号
处理验证码
访问收藏页
访问订单页
填写个人信息
点击收藏
跳转支付页
```

### high：禁止执行

```text
自动下单
自动支付
绕过验证码
绕过风控
逆向接口
高频抓取
多账号并发
```

## 10.3 Python 伪代码

```python
class ActionDecision:
    ALLOW = "allow"
    REQUIRE_HANDOFF = "require_handoff"
    BLOCK = "block"

def judge_action(action: dict) -> dict:
    url = action.get("url", "")
    target = action.get("target", "")
    page_text = action.get("page_text", "")

    high_risk_keywords = ["支付", "提交订单", "确认付款", "pay", "checkout"]
    medium_risk_keywords = ["登录", "验证码", "手机号", "身份证", "护照", "订单", "收藏"]

    content = f"{url} {target} {page_text}".lower()

    if any(k.lower() in content for k in high_risk_keywords):
        return {
            "decision": ActionDecision.BLOCK,
            "risk_level": "high",
            "reason": "涉及支付或下单，禁止自动执行"
        }

    if any(k.lower() in content for k in medium_risk_keywords):
        return {
            "decision": ActionDecision.REQUIRE_HANDOFF,
            "risk_level": "medium",
            "reason": "涉及登录、验证码或个人信息，需要用户接管"
        }

    return {
        "decision": ActionDecision.ALLOW,
        "risk_level": "low",
        "reason": "低风险浏览动作，允许自动执行"
    }
```

## 11. MCP Browser Tool 封装

不要让 Agent 直接裸调用所有 Chrome DevTools MCP 原子工具。

推荐封装为业务工具：

```text
search_web_page(query)
open_public_page(url)
read_current_page()
extract_hotel_page()
extract_travel_note_page()
safe_click(target)
wait_user_handoff()
```

### 11.1 BrowserTool 伪代码

```python
class BrowserTool:
    def __init__(self, mcp_client, action_guard):
        self.mcp_client = mcp_client
        self.action_guard = action_guard

    async def open_page(self, url: str):
        decision = self.action_guard.judge({
            "action": "open_page",
            "url": url
        })

        if decision["decision"] == "block":
            raise Exception(decision["reason"])

        if decision["decision"] == "require_handoff":
            return {
                "status": "need_user_handoff",
                "reason": decision["reason"]
            }

        return await self.mcp_client.call_tool("open_page", {"url": url})

    async def read_page(self):
        return await self.mcp_client.call_tool("read_page_text", {})

    async def screenshot(self):
        return await self.mcp_client.call_tool("screenshot", {})

    async def safe_click(self, target: str, page_text: str, url: str):
        decision = self.action_guard.judge({
            "action": "click",
            "target": target,
            "page_text": page_text,
            "url": url
        })

        if decision["decision"] == "block":
            return {
                "status": "blocked",
                "reason": decision["reason"]
            }

        if decision["decision"] == "require_handoff":
            return {
                "status": "need_user_handoff",
                "reason": decision["reason"]
            }

        return await self.mcp_client.call_tool("click", {"target": target})
```


## 17. 核心实现原则

```text
1. Agent 直接使用 Chrome DevTools MCP。
2. 用户只负责输入需求和接管敏感操作。
3. 所有浏览器动作先过 Action Guard。
4. 低风险动作自动执行。
5. 中风险动作暂停让用户处理。
6. 高风险动作禁止。
7. 页面内容只读取用户可见内容。
8. 所有抽取结果结构化保存。
9. 行程生成支持多轮修改。
10. 第一版以能自用为目标，不追求平台复杂度。
```
