# 安卓原生界面分层（阶段 0 + 1）

## 入口和生命周期

`MainActivity.kt` 保留旧版导出组件名、正式包名和 App Links，承接 Compose UI 与通知式更新检查。`TongyouApplication` 持有会话和 API；原 Java 容器移为未导出的 `WebFallbackActivity`，保留文件选择、分享、打印、网页返回与更新行为。未迁移页面通过原生按钮直达对应网页功能。

原生三项底栏为旅行、记账、我的；旅行首页、我的概览和 AI 为 Compose，记账与账户高级功能进入兜底。Navigation Compose 管理原生返回栈。后续阶段可逐步用新 composable 替换 fallback 路由，不需要替换会话或网络层。

## 会话和网络

- `TokenVault`：Android Keystore AES-GCM，SharedPreferences 只存密文和迁移标记。
- `LegacySession`：仅首次启动同 origin 离线 WebView 读取旧 token；不请求线上业务页面。
- `Session`：登录/注册/恢复/退出/401；compare-token 防止旧请求注销新账号。
- `TravelApi`：固定 API origin、序列化/上传、错误信息转换、可取消请求、不跟随重定向；图片不携带 token。
- `SessionService`：旧页面的请求与返回必须属于同一会话，生产实例捕获请求 token，不动态借用新账号凭证。

## 聊天

`ChatModel` 将提交、轮询、停止、上传与草稿独立于 composable。发送互斥；GET 按 800ms 串行调用；断网按最多 10 秒间隔重试；页面暂停时停止轮询，返回时恢复。服务器是否继续生成由后端负责，退出页面不会擅自停止任务。

`ChatScreen` 提供输入、深度/联网开关、历史、图片、思考、追问、地点、来源与进度。位置只在附近问题下请求粗略权限并最多等待 5 秒，不持久化。`Markdown` 以 CommonMark AST + GFM tables 渲染 Compose Text/列表/引用/代码/横滑表格与 Coil 图片，HTML 只作为文字显示。流式内容跟随系统动态设置渐进展示。

## Android 独有网页适配

`scripts/vite-native.mjs` 使用已有 React 动作注入 chat/trips/createTrip/ledger/account/history/notifications 七种路由。插件仅作用于 APK 打包流程；源码锚点改变时明确失败，不能悄悄构建一个回错页面的包。

`WebFallbackActivity` 在 document start 同步 token 与路由；桥消息仅接受可信主框架。旧版网页测试保留，用例类改为打开该容器。

## 依赖与限制

锁定 Kotlin/Compose compiler 2.1.20、Compose BOM 2025.04.01、Navigation 2.9.0、OkHttp 4.12.0、serialization 1.8.1、Coil 2.7.0、Haze 1.5.3、CommonMark 0.24.0。选用与 AGP 8.9.1 / compileSdk 35 兼容的版本，不依赖最新版本漂移。

Haze 的源与效果层分离，API 31 以下或系统关闭动画时使用半透明实色。实现依据 [Haze 1.5.3 用法](https://github.com/chrisbanes/haze/blob/1.5.3/docs/usage.md) 和 [Compose compiler 配置文档](https://developer.android.com/develop/ui/compose/compiler)。本轮未完成设备上的模糊观感/性能验证。

构建产物写 `android/app/build`；正式签名本地归档可用 `scripts/package-release.py`。此重构未修改后端、Web 或 iOS 的源码和发布状态。
