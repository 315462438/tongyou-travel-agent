# 旅行预算测算

## 何时使用
用户问题涉及金额：预算是否够用、总花费预估、多人/多天费用分摊。

## 费用拆分口径
固定拆成以下几类，缺哪类就注明"未计入"，不要含糊合并：
1. **大交通**：往返机票/高铁（价格随日期波动大，报一个区间而不是单值）
2. **住宿**：按档次给出每晚价格区间 × 晚数（携程来源优先，标注来源）
3. **市内交通**：打车/地铁/租车，按天数估算日均
4. **餐饮**：按当地物价水平给日均区间（人均，不是家庭总额）
5. **门票/体验**：列出计划里的主要付费项目及票价
6. **其他/浮动**：购物、突发情况，建议按小计的 10%-15% 留余量

## 计算过程要可见
凡是涉及金额加总或人均换算，**把算式写出来**（如"住宿 400×3晚 + 餐饮 150×2人×3天 = 2100"），
不要只给最终数字——这是用户核对预算是否踩坑的关键，跳过算式等于没测算。

## 呈现格式
- 一张分类明细表（类别 / 单价区间 / 数量 / 小计）
- 表格下方给总计区间（不要给单一数字，旅行开销天然有浮动）
- 结论句直接回答"够/紧张/富余"，并指出最容易超支的那一项

## 常见坑
- 用了过时或凭印象的价格——机票酒店这类波动项必须有实时来源支撑，说不准就标"仅供参考，请查询实时价格"
- 忘记人数换算：住宿是按房间算、餐饮门票是按人头算，两者不能用同一个乘数
- 只给总数不给分类，用户没法判断该砍哪一项
