# 签证/入境政策类问题求证

## 何时使用
用户问题涉及"要不要签证/免签多久/需要什么材料/落地签"等官方政策类问题。

## 求证顺序
1. 优先信任**使领馆/移民局官网**或权威政府发布的信息；旅游博客/攻略帖只作为材料清单
   的补充参考，不能作为政策是否变化的依据
2. 政策类信息**变化频繁**（免签协议、落地签条件常调整），search 时优先用带年份的
   关键词（如"2026 XX 免签政策"）而不是笼统搜索，避免命中过时文章
3. 同一政策若多个来源冲突，以发布时间更新、来源更官方的为准，并在报告里说明有分歧

## 输出结构（按顺序给全，缺一项就注明"未查到"）
1. **是否需要签证**（免签/落地签/需提前办理）及可停留天数
2. **所需材料清单**
3. **办理渠道和大致时长**（使领馆 / 线上 / 落地）
4. **费用**（如有）
5. **时效性免责声明**：明确写出"以上信息可能随政策调整变化，请在出行前以官方渠道
   最新公告或使领馆咨询为准"——这是必须项，不能省略

## 常见坑
- 把某篇旧攻略里的政策当成当前有效结论，不加时间/时效说明
- 混淆"免签"和"落地签"（材料和费用完全不同，不能笼统一句带过）
- 只回答"要不要签证"，漏了材料清单——用户下一句大概率追问材料
