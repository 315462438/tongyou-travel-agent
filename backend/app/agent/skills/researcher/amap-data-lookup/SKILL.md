# 高德数据查询技巧

## 何时使用
主 agent 派来的收集任务涉及：城市天气、热门景点、核实某地点/酒店/餐馆是否存在及坐标。

## 工具选择
- **`amap_city_brief(city)`**：一次性拿到「天气预报 + 热门景点评分坐标」，是天气/景点类
  任务的**首选且唯一入口**——不要为了查天气再单独想别的办法，这个工具就是为此设计的
- **`amap_poi(keyword, city)`**：核实**具体、已知名字**的地点（某酒店、某餐馆、某景点）
  是否存在及精确坐标，跟 `amap_city_brief` 的"某城市热门景点是什么"是两类问题

## 城市名规范化
- 用**地级市/城市官方名**，不要用区县名或俗称（"鼓浪屿"传"厦门"，不要直接传"鼓浪屿"）
- 主 agent 一次任务里如果涉及多个城市，在一次子任务里把所有城市列出来分别调用，
  不要拆成多个子任务往返——子任务派发本身有开销

## 批量处理
一个子任务如果要查 3 个城市的天气，在这一次子任务执行内连续调用 3 次
`amap_city_brief`，把结果汇总成一份报告返回，不要要求主 agent 拆成 3 次派发。

## 常见坑
- 传了区县/景点名给 `amap_city_brief` 导致查不到数据——退一级用地级市名重试
- 把"某地有什么好玩的"当成 `amap_poi` 任务——那是 `amap_city_brief` 的景点列表职责
