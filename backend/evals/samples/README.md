# 抽取评估的固定样本

这里放**真实线上攻略正文**，是 `evals/extract.yaml` 的输入。样本必须固定不变——
换了输入就不是同一个评估集，前后对照失去意义。

样本本身**不进 git**（见仓库根 `.gitignore`）：它们是真实用户会话的产物，
虽然是模型生成的攻略正文、已核对过不含手机号/证件号/邮箱，但没有必要
把用户内容放进代码仓库。

拉取（需要服务器访问权）：

    .venv/bin/python -m evals.fetch_samples

`extract.yaml` 里记了每条样本的 `message_id` 与 `sha256`，拉下来会校验哈希，
对不上就报错——防止「样本悄悄变了但期望没改」这种最难查的评估失真。
